## W25Q64 Flash 工作原理（必须理解）

Flash 存储器与普通RAM有本质区别：

| 特性 | Flash（W25Q64） | 普通RAM |
|------|----------------|---------|
| 写之前 | 必须先**擦除**（变成全0xFF） | 直接写 |
| 擦除单位 | **最小4KB扇区**（Sector Erase） | 按字节 |
| 写入单位 | 最大**256字节页**（Page Program） | 按字节 |
| 写操作前 | 必须先发**写使能**命令 | 无需 |
| 每次操作后 | 必须**轮询BUSY位**等待完成 | 无需 |
| 读操作 | 相对简单，直接发地址连续读 | 直接访问 |

---

## W25Q64 指令集（需要用到的命令）

| 命令名 | 指令码 | 说明 |
|--------|--------|------|
| Write Enable | `0x06` | 写/擦除操作前必须先发这个 |
| Read Status Register | `0x05` | 读状态，bit0=BUSY（1=忙，0=空闲）|
| Sector Erase (4KB) | `0x20` | 擦除4KB扇区，需要24位地址 |
| Page Program | `0x02` | 写最多256字节，需要24位地址+数据 |
| Read Data | `0x03` | 读数据，需要24位起始地址 |

## 完整写操作流程（实现 `Flash_WritePIDParams` 的步骤）

```
Step 1: 发送 0x06（写使能）
   NSS_FLASH_LOW()
   SPI_Transfer(0x06)
   NSS_FLASH_HIGH()

Step 2: 发送 0x20（扇区擦除）+ 24位地址（如0x000000）
   NSS_FLASH_LOW()
   SPI_Transfer(0x20)
   SPI_Transfer(0x00)  // 地址高字节
   SPI_Transfer(0x00)  // 地址中字节
   SPI_Transfer(0x00)  // 地址低字节
   NSS_FLASH_HIGH()

Step 3: 等待擦除完成（轮询BUSY位，擦除约需100ms）
   do {
       NSS_FLASH_LOW()
       SPI_Transfer(0x05)          // Read Status Register
       status = SPI_Transfer(0x00) // 读回状态字节
       NSS_FLASH_HIGH()
   } while (status & 0x01)         // bit0=BUSY，等到为0

Step 4: 再次发送 0x06（写使能，每次写操作前都要重新使能）

Step 5: 发送 0x02（页编程）+ 地址 + 16字节数据（4个float × 4字节）
   NSS_FLASH_LOW()
   SPI_Transfer(0x02)
   SPI_Transfer(0x00); SPI_Transfer(0x00); SPI_Transfer(0x00)
   // 发送4个float的16字节（用memcpy把float转成字节数组）
   for (i = 0; i < 16; i++) SPI_Transfer(data[i])
   NSS_FLASH_HIGH()

Step 6: 等待写完成（同Step 3，页编程约需3ms）
```

## 完整读操作流程（实现 `Flash_ReadPIDParams` 的步骤）

```
Step 1: 发送 0x03（读命令）+ 24位起始地址
   NSS_FLASH_LOW()
   SPI_Transfer(0x03)
   SPI_Transfer(0x00); SPI_Transfer(0x00); SPI_Transfer(0x00)

Step 2: 连续读出16字节（发0x00占位，从机自动返回数据）
   for (i = 0; i < 16; i++) data[i] = SPI_Transfer(0x00)
   NSS_FLASH_HIGH()

Step 3: 把字节数组重组为4个float
   memcpy(&kp_speed,   &data[0],  4)
   memcpy(&ki_speed,   &data[4],  4)
   memcpy(&kp_current, &data[8],  4)
   memcpy(&ki_current, &data[12], 4)
```

## 如何验证Flash工作正常（测试方法）

```
1. 写入已知值：Flash_WritePIDParams(1.1, 0.2, 0.3, 0.4)
2. UART打印"写入完成"
3. 按STM32复位按钮（重启）
4. 读取：Flash_ReadPIDParams(...)
5. UART打印读出的值
6. 若打印出 1.1 / 0.2 / 0.3 / 0.4，则Flash工作正常 ✓
```
