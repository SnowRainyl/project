# RC低通滤波器 — 电位器ADC输入滤波

## 为什么需要这个电路

电位器（电阻分压器）输出的电压上会叠加来自电机PWM开关的高频噪声，
如果直接接ADC，采样值会跳动，导致目标转速不稳定。

RC低通滤波器的作用：让低频信号（手缓慢转动电位器，≈几Hz）通过，
过滤掉高频噪声（PWM频率20kHz），让ADC采样更稳定。

---

## 电路图（面包板上搭建）

```
电位器中间脚
     │
     ├──── R（1kΩ）────┬──── 接 STM32 PA1（ADC通道）
     │                  │
     │                  C（1µF 电解电容）
     │                  │
     │                 GND（负极）
     │
    GND
```

> **电容注意**：电解电容有正负极，长脚（+）接信号线，短脚（-）接GND

---

## 元件选择（用你现有的材料）

| 元件 | 值 | 来自你的清单 |
|------|----|------------|
| R（电阻） | 1kΩ 金属膜电阻 | 清单材料14号（1/4W 1KΩ）|
| C（电容） | 1µF 电解电容 | 清单设备3号（电解电容包）|

截止频率：f_c = 1 / (2π × R × C) = 1 / (2π × 1000 × 0.000001) ≈ **159 Hz**

含义：159Hz以下的信号正常通过（电位器转动很慢），159Hz以上的噪声被衰减。

## 接线位置（面包板）

```
电位器（WH148 / B5K）接线：
  左脚 → 3.3V
  右脚 → GND
  中间脚 → 经RC滤波后接 STM32 PA1
```

```
完整电路（在面包板上）：
  电位器中间脚 ──→ 1kΩ电阻（行方向放置）──→ A点
  A点 ──→ 1µF电解电容正脚
  1µF电解电容负脚 ──→ GND
  A点 ──→ 杜邦线 ──→ STM32 PA1
```

## 为什么这满足课程"AD/DA"的非平凡要求

老师原话："not enough to just use a converter on a board"

本设计的AD部分做了两件不平凡的事：

1. **硬件RC滤波**：设计并搭建模拟滤波电路，不是直接接ADC
2. **软件滑动平均滤波**：在 `adc.c` 里对最近8次采样取平均，双重滤波
3. **两路ADC**：通道1=电位器（目标速度），通道2=INA240（实际电流）
4. **INA240精密放大**：分流电阻 → 微伏级信号 → INA240放大20倍 → STM32 ADC能读

这些组合起来，构成了一个完整的、经过设计的信号调理链（Signal Conditioning Chain），远不是"just use a converter on a board"。
