# 阶段1：UART调试 — 完整步骤指南

**目标**：让STM32通过UART发送文字到电脑，在串口助手里看到 `Hello, UART!`

**完成标志**：电脑串口助手里能看到STM32发来的文字 ✓

---

## 所需材料

| 材料 | 数量 | 清单中的位置 |
|------|------|------------|
| STM32F103C8T6 最小系统板 | 1 | 清单材料20号 |
| USB转TTL CH340 模块 | 1 | 清单材料6号（或设备4号）|
| 杜邦线（母对母） | 4根 | 清单材料7号 |

> ⚡ **不需要接电机、FPGA、OLED等任何其他模块**，本阶段只需以上5样。

## 第一步：安装软件（第一次做，以后不用重复）

按顺序安装以下软件：

### 1.1 安装 Keil MDK 5
- 去 **keil.com** 下载 "MDK-Arm"（当前版本MDK5）
- 安装时全程默认，路径不要有中文和空格
- 安装完成后，打开 Keil → 菜单 `Pack Installer` → 搜索 `STM32F1` → 安装 **Keil::STM32F1xx_DFP**（芯片支持包）
- ⚠️ Keil MDK 超过32KB代码需要License，学生可申请免费License或使用STM32CubeIDE（完全免费）

### 1.2 安装 ST-Link 驱动
- 去 st.com 搜索 **STSW-LINK009** 下载并安装
- 安装后插入ST-Link，设备管理器里能看到 "STMicroelectronics ST-Link" 则成功

### 1.3 安装 CH340 驱动
- 去 **wch.cn** 下载 CH340 驱动并安装
- 安装后插入CH340模块，设备管理器里能看到 "USB-SERIAL CH340 (COMx)" 则成功
- **记下是几号COM口**（比如COM3），后面串口助手要用

### 1.4 安装串口助手 SSCOM
- 搜索下载 **SSCOM5.13.1**（免费小工具，国内常用）
- 解压即用，不用安装

## 第二步：硬件接线

需要接两组线：
- **ST-Link → STM32**：用于烧录程序
- **CH340 → STM32**：用于UART通信

### ST-Link 接线（烧录用）

```
ST-Link引脚    →    STM32最小系统板引脚
─────────────────────────────────────
SWDIO          →    PA13（或板子标注的 DIO/SWDIO）
SWCLK          →    PA14（或板子标注的 CLK/SWCLK）
GND            →    GND
3.3V           →    3.3V（给STM32供电）
```

> STM32最小系统板上通常有专门的4针SWD调试接口，对着插就行。

### CH340 接线（UART通信用）

```
CH340模块引脚  →    STM32最小系统板引脚
─────────────────────────────────────
TXD（发送）    →    PA10（STM32的RX接收引脚）
RXD（接收）    →    PA9（STM32的TX发送引脚）
GND            →    GND（必须共地！）
```

> ⚠️ **注意交叉连接**：CH340的TX接STM32的RX，CH340的RX接STM32的TX
> ⚠️ **不要连VCC**：STM32已经由ST-Link的3.3V供电，CH340的VCC不用接

### 接线示意图

```
    [电脑USB]
       │
   [ST-Link]────SWDIO──→ STM32 PA13
       │    ────SWCLK──→ STM32 PA14
       │    ────3.3V──→  STM32 3.3V
       │    ────GND──→   STM32 GND
       │
    [电脑USB]
       │
   [CH340]─────TXD───→  STM32 PA10(RX)
              ─RXD───←  STM32 PA9(TX)
              ─GND──→   STM32 GND（共地）
```

## 第三步：在Keil里新建工程

### 3.1 新建工程
1. Keil → `Project` → `New µVision Project`
2. 选择保存位置：`Project/STM32/`，工程名填 `motor_control`
3. 弹出芯片选择：搜索 `STM32F103C8`，选中后点 OK
4. 弹出组件选择窗口（RTE）：只勾选 `CMSIS → CORE`，其他不选，点 OK

### 3.2 添加源文件
在Keil左侧 `Project` 目录树里：
1. 右键 `Source Group 1` → `Add Existing Files`
2. 添加以下文件：
   - `STM32/Src/main.c`
   - `STM32/Src/uart.c`
3. 右键项目根节点 → `Add Group` → 新建 `Inc` 组（用于组织，非必须）

### 3.3 设置头文件路径
`Project` → `Options for Target` → `C/C++` → `Include Paths` → 添加 `../Inc`

### 3.4 调整main.c（阶段1暂时简化）
阶段1先把 `main.c` 改得最简单，只测试UART：

```c
// 阶段1测试用 main.c（临时简化版）
#include "uart.h"

static void delay(int n) {
    for (int i = 0; i < n * 8000; i++) __asm("nop");
}

int main(void) {
    UART_Init();
    while (1) {
        UART_SendString("Hello, UART!\r\n");
        delay(500);  // 每500ms发一次
    }
}
```

## 第四步：理解 UART 寄存器（核心知识点）

> 📖 对应 RM0008 参考手册第27章（USART）

STM32F103 的 UART 初始化只需要配置4个寄存器：

```
需要操作的寄存器：
┌──────────────┬──────────────────────────────────────────┐
│ RCC->APB2ENR │ 打开 GPIOA 和 USART1 的时钟             │
│ GPIOA->CRH   │ 配置 PA9(TX) 和 PA10(RX) 的引脚功能     │
│ USART1->BRR  │ 设置波特率（115200）                     │
│ USART1->CR1  │ 使能发送功能 + 使能USART                 │
└──────────────┴──────────────────────────────────────────┘
```

**时钟树说明**（STM32上电默认用HSI内部时钟 8MHz）：

```
HSI(8MHz) → 系统时钟 8MHz → APB2总线 8MHz → USART1
```

> 阶段1先用默认8MHz，之后再学PLL配置到72MHz。

**波特率计算**：

```
BRR寄存器值 = 系统时钟 ÷ 波特率 ÷ 16
BRR = 8,000,000 ÷ 115200 ÷ 16 = 4.34...

分成整数部分和小数部分：
  整数部分（Mantissa）= 4      → 存入 BRR[15:4]
  小数部分 = 0.34 × 16 = 5.44 → 取整5 → 存入 BRR[3:0]
  最终 BRR = (4 << 4) | 5 = 0x45
```

**引脚配置说明**（CRH寄存器，每个引脚4位）：

```
PA9（TX，输出）：复用推挽输出 50MHz
  CNF[1:0] = 10（复用推挽），MODE[1:0] = 11（50MHz）→ 4位值 = 0b1011 = 0xB

PA10（RX，输入）：浮空输入
  CNF[1:0] = 01（浮空输入），MODE[1:0] = 00（输入）→ 4位值 = 0b0100 = 0x4

CRH寄存器布局（高16位控制PA8~PA15）：
  PA9在CRH的bit[7:4]，PA10在CRH的bit[11:8]
```

## 第五步：编写 uart.c 完整代码

打开 [STM32/Src/uart.c](../../STM32/Src/uart.c)，已经包含了完整实现，核心寄存器操作如下：

```c
void UART_Init(void) {
    // 1. 打开时钟
    RCC->APB2ENR |= (1 << 2);   // IOPAEN：GPIOA时钟
    RCC->APB2ENR |= (1 << 14);  // USART1EN：USART1时钟

    // 2. 配置引脚（操作CRH寄存器，控制PA8~PA15）
    GPIOA->CRH &= ~(0xFF << 4); // 清除PA9和PA10原有配置
    GPIOA->CRH |=  (0xB << 4);  // PA9: 复用推挽输出（TX）
    GPIOA->CRH |=  (0x4 << 8);  // PA10: 浮空输入（RX）

    // 3. 设置波特率（8MHz系统时钟，115200波特率）
    USART1->BRR = 0x45;

    // 4. 使能USART：TE（发送使能）| UE（USART使能）
    USART1->CR1 = (1 << 3) | (1 << 13);
}

void UART_SendChar(char c) {
    while (!(USART1->SR & (1 << 7)));  // 等待发送缓冲区空（TXE位）
    USART1->DR = c;                     // 写入数据寄存器，自动发送
}
```

```
...
```

## 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 串口助手没有输出 | CH340未安装驱动 | 检查设备管理器是否有COM口 |
| 串口助手显示乱码 | 波特率不对 | 确认SSCOM选了115200 |
| 乱码（部分正确） | 接线TX/RX接反 | 把CH340_TX和CH340_RX对调 |
| Keil编译报错"cannot open source" | 头文件路径未设置 | 检查Include Paths是否加了`../Inc` |
| ST-Link烧录失败 | SWD接线错误或STM32未供电 | 检查SWDIO/SWCLK/GND/3.3V四根线 |
| 编译0错误但运行没反应 | 忘了按复位 | 烧录后按STM32板上的RESET按钮 |
