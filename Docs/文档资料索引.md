# 文档资料索引

本项目所有需要查阅的数据手册和参考文档。
**所有文档均免费，可在官方网站或下方说明的渠道下载。**

---

## STM32 相关

| 文档名 | 作用 | 下载方式 |
|--------|------|---------|
| **STM32F103C8T6 数据手册 (Datasheet)** | 引脚定义、电气参数、封装图 | st.com 搜索 "STM32F103C8T6 datasheet" |
| **STM32F10x 参考手册 (Reference Manual RM0008)** | ⭐ 最重要！寄存器定义、外设配置（ADC/TIM/SPI/I2C/UART全在这里） | st.com 搜索 "RM0008" |
| **STM32F10x 编程手册 (PM0056)** | Cortex-M3内核指令、SysTick等 | st.com 搜索 "PM0056" |
| **Keil MDK 入门指南** | IDE使用、工程创建、调试方法 | keil.com 或搜索 "Keil MDK 新建STM32工程教程" |

> 最常用的是 **RM0008**，写寄存器代码时随时翻。建议下载PDF保存本地。
