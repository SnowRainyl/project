\chapter*{摘要}
\addcontentsline{toc}{chapter}{摘要}
\markboth{摘要}{摘要}

本报告介绍了一种基于 STM32F407 微控制器与 AX309 FPGA 开发板的直流电机串级闭环控制系统的设计与实现。系统采用速度外环与电流内环构成的串级PID控制结构，实现了 0 至 100 RPM 范围内的平滑调速。

系统所有外设驱动均采用寄存器级 C 语言编写，包括 UART、ADC、SPI、I2C 及 TIM3 正交编码器接口。FPGA 采用 VHDL 实现 12 位 PWM 发生器，PWM 频率约为 12.2\,kHz，通过 SPI 接收 STM32 发送的占空比指令。电机电流由 INA240A2 双向电流分流监视器采样后送入电流内环，编码器转速反馈则闭合速度外环。

实验结果表明：系统稳态转速误差低于 1\%，PWM 频率实测为 12.207\,kHz（与理论值 50\,MHz/4096 完全吻合），空载电流约为 30\,mA，与电机铭牌一致。

\vspace{1em}
\noindent\textbf{关键词：}串级PID，STM32F407，FPGA，直流电机控制，电流采样，寄存器级编程，VHDL

\chapter{系统分析与设计}

\section{功能需求与可行性分析}

本项目的主要目标是实现一套满足以下要求的直流电机闭环调速系统：

\begin{itemize}
    \item 调速范围：0--100\,RPM，由旋钮电位器进行用户设定
    \item 稳态转速误差：$<1\%$
    \item OLED 实时显示转速、占空比及电机电流
    \item 通过 UART 以 115200\,baud 输出串口调试信息
    \item 使用 SPI Flash（W25Q64）进行 PID 参数非易失性存储
\end{itemize}

\section{控制策略：为何选择串级PID}

若仅以单环 PID 直接控制转速，当负载电流发生变化时，系统对扰动的抑制能力较弱，响应较慢。通过引入电流内环，电流得到更高带宽的调节，相当于对外环的被控对象进行了线性化处理，从而显著提升整体动态性能。

两个环路均运行于 1\,kHz 采样频率，但整定参数独立：内环采用较高的比例增益，以确保其在一个外环周期内完成收敛。

\subsection{片上外设与地址空间}

STM32F407 属于典型的片上系统（System-on-Chip, SoC）：CPU core、SRAM、Flash 以及 UART、ADC、SPI、I2C、TIM 等外设都集成在同一颗芯片中，但外设并不属于 CPU core 内部。CPU core 通过片上总线访问这些外设，外设则通过一组控制寄存器、状态寄存器和数据寄存器与 CPU 交换信息。

处理器访问外设通常有两种模型：I/O-mapped I/O 与 memory-mapped I/O。I/O-mapped I/O 使用独立于普通内存的 I/O 地址空间，地址更像是一组端口号（port number）。CPU 执行专门的 I/O 指令时，会在总线上发起一次 I/O 访问，并给出端口号；哪个外设被硬件设计为响应该端口号，哪个外设就完成对应的数据读写。因此，I/O 地址空间并不是一块“小内存”，也不是 RAM 的一部分，而是由 CPU 架构和总线协议定义的独立端口编号空间。

Memory-mapped I/O 则将外设寄存器映射到普通内存地址空间中。CPU 使用普通的 load/store 指令访问某个地址时，地址译码逻辑会判断该地址对应 RAM、Flash 还是某个外设寄存器。如果地址落在外设区域，访问就会被转发给对应外设。例如 GPIO、USART 或 SPI 的寄存器地址虽然写成类似内存地址的形式，但实际访问对象是外设寄存器，而不是 SRAM。

本项目使用的 STM32F407 采用 memory-mapped I/O 模型。也就是说，程序中的寄存器级驱动本质上就是通过 C 语言指针或 CMSIS 结构体访问固定地址处的外设寄存器，例如使能 RCC 时钟、配置 GPIO 复用功能、设置 USART 波特率或读写 SPI 数据寄存器。由于 CPU 与外设位于同一芯片内部，数据不需要离开集成电路，通信延迟和功耗都较低。

\section{FPGA PWM 发生模块（AX309 Spartan-6）}

\subsection{FPGA 的角色}

FPGA 作为专用 PWM 发生器，接收 STM32 通过 SPI 发送的 12 位占空比数值，输出对应的 PWM 信号至 TB6612FNG 电机驱动器。这一设计将实时 PWM 生成从 MCU 卸载至 FPGA，同时实现了比 STM32 定时器更高的 PWM 频率。

\subsection{PWM 频率推导}

AX309 开发板板载 50\,MHz 晶振。12 位计数器计至 4096 后归零，因此：

\begin{equation}
    f_{\text{PWM}} = \frac{f_{\text{clk}}}{2^{12}} = \frac{50 \times 10^6}{4096}
    \approx 12.207\,\text{kHz}
    \label{eq:pwm_freq}
\end{equation}

该频率高于人耳可闻范围，且具有足够分辨率（最低有效位 $= 100\,\%/4096 \approx 0.024\,\%$），可实现平滑调速。逻辑分析仪实测值：12.207\,kHz，与理论值完全吻合。

\section{电机驱动电路（TB6612FNG）}

\section{传感系统}

\subsection{转速传感：编码器与 TIM3 正交解码}

JGA25-370 电机内置霍尔效应正交编码器。TIM3 配置为编码器模式 3（两路信号的上升沿与下降沿均计数），实现 $\times4$ 分辨率倍增。每 1\,ms 计算一次转速：

\begin{equation}
    \text{RPM} = \frac{\Delta_{\text{count}} \times 60{,}000}
                      {N_{\text{PPR}}}
    \label{eq:rpm}
\end{equation}

其中 $\Delta_{\text{count}}$ 为有符号 16 位计数器差值（自动处理溢出），$N_{\text{PPR}}$ 为每转脉冲数（含减速比与 $\times4$ 模式）。软件对原始 RPM 做 8 点滑动均值滤波，硬件数字滤波器（IC1F = IC2F = 0001，2 采样）用于抑制短脉冲干扰。

\subsection{电流传感：INA240A2 信号链}

\begin{figure}[H]
    \centering

    \fbox{\parbox{0.7\textwidth}{\centering\vspace{1.5cm}

INA240A2（增益 = 50\,V/V）检测 0.1\,$\Omega$ 采样电阻两端的压差，输出电压为：

\begin{equation}
    V_{\text{out}} = V_{\text{ref}} + G \cdot I \cdot R_{\text{shunt}}
    \label{eq:ina240_out}
\end{equation}

其中 $V_{\text{ref}} = V_{\text{CC}}/2$。实测零电流基准为 $V_{\text{ref}} = 1773\,\text{mV}$（ADC 原始值约 2200）。电机电流计算公式为：

\begin{equation}
    I\,[\text{mA}] = \frac{V_{\text{out}}\,[\text{mV}] - 1773}
                         {50 \times 0.1}
                  = \frac{V_{\text{out}} - 1773}{5}
    \label{eq:current}
\end{equation}

验证：空载 100\,RPM 时实测电流约 30\,mA，与 JGA25-370 铭牌一致。

\subsection{转速给定：电位器与 RC 低通滤波器}

旋钮电位器连接至 PA0（ADC1\_IN0），提供目标转速参考值。电位器滑动端经 RC 低通滤波器（$f_c = 1/(2\pi RC)$）后接入 ADC，用于抑制电源噪声。软件层对采样值进行 16 点滑动均值滤波，并设置死区（ADC 原始值 $< 50 \Rightarrow$ 目标转速 $= 0$），消除零点附近的漂移抖动。

\section{寄存器级外设驱动}

\subsection{UART — 串口调试（USART2）}

\subsubsection*{开发查找逻辑}

寄存器级外设开发的查阅过程并非"直接找引脚"，而是遵循固定的两步路径，以 USART2 为例说明如下。

\textbf{第一步：查 RM0090（知道配什么）}

打开 RM0090 第 30 章 USART，可得知使用 USART2 需要完成四件事：
\begin{enumerate}
    \item 使能 USART2 时钟（\texttt{RCC->APB1ENR} bit17）及 GPIO 时钟（\texttt{RCC->AHB1ENR} bit0）
    \item 将对应引脚配置为复用功能（AF）模式，选择 USART2 对应的 AF 编号
    \item 向 BRR 寄存器写入波特率分频值
    \item 设置 CR1 寄存器使能发送（TE）、接收（RE）与 USART 总开关（UE）
\end{enumerate}

RM0090 到此为止。但第 2 步存在一个信息缺口：\textbf{RM 只告诉你"需要配 AF 模式"，但不说明 USART2 对应 AF 几、应选哪个物理引脚}。这是 RM 与 Datasheet 职责的分界点。

\textbf{第二步：查 DS8626 Table 9（知道用哪个引脚）}

DS8626 的 Table 9 是 STM32F407 全部引脚的复用功能对照表，按外设名检索 ``USART2'' 可得：

\begin{center}
\begin{tabular}{lll}
    \toprule
    \textbf{引脚} & \textbf{AF 编号} & \textbf{功能} \\
    \midrule
    PA2 & AF7 & USART2\_TX \\
    PA3 & AF7 & USART2\_RX \\
    PD5 & AF7 & USART2\_TX（备选） \\
    PD6 & AF7 & USART2\_RX（备选） \\
    \bottomrule
\end{tabular}
\end{center}

本项目选用 PA2/PA3，因为这两个引脚在 STM32F407G-DISC1 开发板上已通过板内走线连接至 ST-Link 芯片（虽然该 VCP 链路最终确认失效）。AF 编号 7 即为写入 \texttt{GPIOA->AFR[0]} 寄存器的数值。

\textbf{查阅逻辑总结：}
\[
\text{RM0090（配什么寄存器）}
\xrightarrow{\text{AF编号缺口}}
\text{DS8626 Table 9（用哪个引脚、AF 几）}
\xrightarrow{}
\text{回 RM0090 写寄存器}
\]

入口永远是 RM0090，DS8626 仅在需要引脚/AF 信息时介入，其余步骤全部在 RM 内完成。

\subsubsection*{寄存器配置}

USART2 配置为 115200\,baud，8N1 格式。引脚 PA2（TX）、PA3（RX）配置为 AF7，推挽输出，无上下拉。APB1 = 42\,MHz 时，波特率寄存器计算如下：
\begin{equation}
    \text{USARTDIV} = \frac{f_{\text{APB1}}}{16 \times \text{BaudRate}}
    = \frac{42{,}000{,}000}{16 \times 115{,}200} \approx 22.786
    \quad\Rightarrow\quad \texttt{BRR = 0x16D}
\end{equation}

发送函数等待 SR 寄存器 TXE 标志位（bit7）置 1 后再向 DR 寄存器写入数据，确保不覆盖尚未发完的字节。本开发板 ST-Link VCP 链路异常无法输出数据，改用外接 CH340G USB 转串口模块（PA2 $\to$ CH340G RXD，PA3 $\leftarrow$ CH340G TXD，TX/RX 交叉连接，共地，COM12，115200\,baud 8N1）。

\subsection{ADC — 双通道采样}

ADC1 采用软件触发，通过 SQR3 寄存器动态切换采样通道。时钟由 APB2（84\,MHz）4 分频得到 21\,MHz。采样时间：高阻抗电位器通道（IN0）设为 84 个周期，低阻抗 INA240 输出通道（IN1）设为 28 个周期。

\subsection{SPI1 — W25Q64 Flash 存储}

本项目两路 SPI 均采用\textbf{软件 NSS}（Software Chip Select）方案，而非 STM32 SPI 外设自带的硬件 NSS 引脚。原因有二：其一，硬件 NSS 固定对应一个引脚且只能管理一个从机，扩展性差；其二，硬件 NSS 输入模式下若检测到外部拉低信号会自动将 STM32 降级为从机，在单主机系统中易引发异常。因此片选均由普通 GPIO 引脚软件控制高低电平实现：SPI1 使用 \textbf{PA4} 作为 W25Q64 的片选线，SPI2 使用 \textbf{PB12} 作为 FPGA 的片选线，两者在 SPI 寄存器中设置 SSM=1、SSI=1 以启用软件 NSS 模式。

通信时序为：拉低片选引脚（选中从机）$\to$ 收发数据字节 $\to$ 拉高片选引脚（释放从机）。

W25Q64FV 指令集包括读 ID（0x90）、页编程（0x02）、扇区擦除（0x20）、读数据（0x03）；写操作前必须先发写使能指令（0x06）。驱动已通过 SPI1 自回环测试（PASS）。注意：芯片目前尚未接线，接线后需重新验证读写功能。

\subsection{SPI2 — FPGA 通信协议}

向 FPGA 发送 12 位占空比数据的帧格式如下：

\begin{verbatim}
CS 拉低
  字节 0：[7:4]=0000  [3:0]=duty[11:8]   （高4位）
  字节 1：[7:0]=duty[7:0]                （低8位）
CS 拉高
\end{verbatim}

CS 边沿作为帧定界符，无需同步头。SPI2 配置为 APB1/8 = 5.25\,MHz，模式 0，8 位 MSB 优先。由于 FPGA 不回传数据，MISO（PB14）可不接线。

\subsection{I2C1 — OLED SSD1306 显示屏}

I2C1 工作于 100\,kHz。APB1 = 36\,MHz 时，CCR 设为 180，TRISE 设为 37。每次 I2C 事务结束后加入超时计数器与标志位清除序列（AF、BERR、ARLO、OVR），防止总线锁死。

\subsection{TIM3 — 正交编码器接口}

TIM3 配置为编码器模式 3（SMCR 寄存器 SMS[2:0] = 011），两路信号的上升沿与下降沿均触发计数。启用 2 采样数字滤波器（IC1F = IC2F = 0001）以抑制噪声。

\section{PID 数学模型}

位置式离散 PID 控制器由连续形式推导而来：

\begin{equation}
    u(t) = K_p\,e(t) + K_i\int_0^t e(\tau)\,d\tau + K_d\,\frac{de(t)}{dt}
\end{equation}

以采样周期 $T$（本项目 $T = 1\,\text{ms}$）离散化后得：

\begin{equation}
    u[n] = K_p\,e[n]
         + K_i \sum_{k=0}^{n} e[k]
         + K_d\,\bigl(e[n] - e[n-1]\bigr)
    \label{eq:pid_discrete}
\end{equation}

积分累积量经限幅处理以防止积分饱和：
\begin{equation}
    \sum e[k] \;\leftarrow\; \text{clamp}\!\left(\sum e[k],\;
    -I_{\max},\; +I_{\max}\right)
\end{equation}

输出量同样限制在 $[u_{\min},\, u_{\max}]$ 范围内。

\section{1\,kHz 控制循环实现}

\texttt{TIM6\_DAC\_IRQHandler} 每 1\,ms 执行一次，执行顺序如下：

\begin{enumerate}
    \item 更新编码器：计算 $\Delta_{\text{count}}$ 并更新滤波后 RPM。
    \item 读取电位器 ADC（16 点均值滤波）；施加死区处理。
    \item \textbf{速度 PID}：$e_\omega = \omega_{\text{ref}} - \omega_{\text{meas}}
          \;\Rightarrow\; I_{\text{ref}}$。
    \item 读取电流 ADC（8 点均值滤波）。
    \item \textbf{电流 PID}：$e_I = I_{\text{ref}} - I_{\text{meas}}
          \;\Rightarrow\; d \in [0, 4095]$。
    \item 通过 SPI2 向 FPGA 发送占空比 $d$（2 字节，约 $3\,\mu$s）。
\end{enumerate}

中断服务函数总执行时间约 $9\,\mu\text{s}$（占 1\,ms 周期的 0.9\%）。

\chapter{FPGA 开发}

FPGA 设计包含三个 VHDL 模块，使用 Xilinx ISE 14.7 综合，目标器件为 Spartan-6 XC6SLX9-2FTG256。

\section{SPI 从机接收器（\texttt{spi\_slave.vhd}）}

\subsection{跨时钟域同步}

SPI 信号（SCK、CS\_N、MOSI）与 FPGA 50\,MHz 时钟异步。采用两级同步链消除亚稳态：

\begin{lstlisting}[style=vhdlstyle, caption={SCK 两级同步链。}]
p_sync : process(clk)
begin
    if rising_edge(clk) then
        sck_d1 <= sck;
        sck_d2 <= sck_d1;
    end if;
end process;
sck_rise <= sck_d1 and (not sck_d2);  -- 单周期上升沿脉冲
\end{lstlisting}

\subsection{接收状态机}

在 CS\_N 为低期间，每检测到一个 SCK 上升沿即移入一位数据。接收满 8 位后锁存高半字节；再接收 8 位后，完整的 12 位占空比在 CS\_N 上升沿被寄存。

\section{PWM 发生器（\texttt{pwm\_gen.vhd}）}

12 位自由计数器与锁存的占空比寄存器进行比较：

\begin{lstlisting}[style=vhdlstyle, caption={PWM 比较器。}]
pwm_out <= '1' when (pwm_cnt < duty_reg) else '0';
\end{lstlisting}

SPI 从机产生的 \texttt{duty\_valid} 选通信号仅在帧边界处更新 \texttt{duty\_reg}，防止在 PWM 周期中途产生毛刺。

\texttt{top.vhd} 例化 \texttt{spi\_slave} 与 \texttt{pwm\_gen}，并在两者之间路由占空比总线。引脚约束在 \texttt{pin.ucf} 中指定；表~\ref{tab:fpga_pins} 列出了 FPGA 引脚分配。

\section{TIM6 1\,kHz PID 控制循环}

\begin{lstlisting}[style=cstyle, caption={TIM6\_DAC\_IRQHandler：1\,kHz 串级PID控制循环。}]
void TIM6_DAC_IRQHandler(void)
{
    if (TIM6->SR & TIM_SR_UIF) {
        TIM6->SR &= ~TIM_SR_UIF;

        Encoder_Update();

        uint16_t adc_val      = ADC1_Read_Filtered();
        float    setpoint_rpm = (adc_val < 50U) ? 0.0f
                             : (float)adc_val * (MOTOR_MAX_RPM / 4095.0f);

        float current_setpoint = PID_Calc(&speed_pid,
                                          setpoint_rpm, g_encoder_rpm);

        float measured_current = ADC1_ReadCurrent_Filtered_mA();

        float    duty_f = PID_Calc(&current_pid,
                                   current_setpoint, measured_current);
        uint16_t duty   = (uint16_t)duty_f;

        uint8_t hi = (duty >> 8U) & 0x0FU;
        uint8_t lo =  duty        & 0xFFU;
        FPGA_CS_LOW();
        SPI2_ReadWriteByte(hi);
        SPI2_ReadWriteByte(lo);
        FPGA_CS_HIGH();

        g_pid_duty = duty;
    }
}
\end{lstlisting}

\section{位置式 PID 实现}

\begin{lstlisting}[style=cstyle, caption={PID\_Calc：带抗积分饱和的位置式PID。}]
float PID_Calc(PID_TypeDef *pid, float setpoint, float feedback)
{
    float err = setpoint - feedback;

    pid->integral += err;
    if      (pid->integral >  pid->integral_max)
        pid->integral =  pid->integral_max;
    else if (pid->integral < -pid->integral_max)
        pid->integral = -pid->integral_max;

    float output = pid->kp * err
                 + pid->ki * pid->integral
                 + pid->kd * (err - pid->err_prev);
    pid->err_prev = err;

    if      (output > pid->out_max) output = pid->out_max;
    else if (output < pid->out_min) output = pid->out_min;
    return output;
}
\end{lstlisting}
