# 速度给定跟踪响应（30 → 60 RPM，空载）

## 测试方法
电机稳定运行于 30 RPM，将电位器快速拧到 60 RPM 档，记录转速跟随过程（5Hz）。

## 性质说明（重要）
本系统给定唯一来自电位器，且软件对给定施加 **10 RPM/s 斜率限幅（setpoint ramp）**
以防扭矩冲击与超调。因此即使旋钮瞬时拧到位，实际给定 `setR` 仍被整形为斜坡：

- `set`（旋钮原始值）：瞬时跳到 60+
- `setR`（斜率限幅后给定）：30 → 60.6 历时 ≈ 3.6s（≈8.5 RPM/s，触及 10 RPM/s 软件上限）
- `RPM`：紧随 `setR`，滞后约 3~5 RPM

故本曲线为**斜坡跟踪响应**，上升速率由 ramp 设定（非闭环带宽）。

## 响应指标

| 指标 | 数值 |
|------|------|
| 初始稳态 | 30.0 RPM（set 29.9） |
| 给定爬升速率 | ≈ 8.5 RPM/s（受 10 RPM/s ramp 限制） |
| 峰值 RPM | 61.2 |
| 超调量 | **≈ 1.0%**（相对终值 60.6） |
| 终值稳态 | ≈ 60.5 RPM，**稳态误差 +0.5%** |
| 给定稳定后收敛时间 | < 1s（约 3~4 个采样） |
| 振荡 | 无（良好阻尼） |

## 结论
RPM 平滑跟随斜坡给定，超调仅 ~1%、无振荡、稳态误差 0.5%。该曲线同时验证了两个设计点：
**① setpoint ramp 防超调**（把旋钮阶跃整形为平缓爬坡）与 **② 闭环良好阻尼**。
建议报告 Fig 6.1 叠绘 `set / setR / RPM` 三条曲线呈现。
