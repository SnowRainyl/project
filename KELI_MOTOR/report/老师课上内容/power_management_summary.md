## 1. 功率器件基础

### 1.1 Diode（二极管）

二极管在功率电路中不仅用于单向导通，还要关注耐压、导通损耗、反向恢复和峰值电流。

#### 核心参数

| 参数 | 含义 |
|---|---|
| \(V_f\) | 正向导通压降，硅二极管常见约 \(0.6\sim0.7\text{ V}\) |
| \(V_{BR}\) | 反向击穿电压 |
| \(t_{rr}\) | 反向恢复时间，关断时需要清除存储电荷 |
| \(I_S\) | 反向漏电流 |
| \(R_{on}\) | 导通电阻，功率应用中越低越好 |

#### 常见类型

| 类型 | 特点 | 典型用途 |
|---|---|---|
| 普通 PN 二极管 | 成本低，速度一般 | 低频整流 |
| PIN 二极管 | 高耐压，适合大功率 | 高压功率应用 |
| Schottky Diode | 正向压降低，开关速度快，但反向漏电较大、耐压较低 | 高频 DC-DC、续流 |
| Zener Diode | 工作在反向击穿区，电压近似恒定 | 简单稳压、参考电压 |

#### 重点

- 功率二极管选择时要看：
  - 最大反向耐压；
  - 最大平均电流；
  - 峰值电流；
  - 正向压降；
  - 反向恢复时间；
  - 功耗与散热。
- 高频开关电源中常用 Schottky 二极管，因为其反向恢复快、损耗低。

> **[项目对照] 续流二极管在 TB6612 里的作用**
>
> 你项目里的电机驱动芯片 **TB6612FNG** 内部集成了 Schottky 二极管（体二极管）。
>
> 问题背景：电机线圈是电感性负载。每次 PWM 信号从高变低（MOSFET 关断），线圈里的电流不能瞬间消失，它需要一条"泄放路径"，否则会产生非常高的反向电压，瞬间击穿开关管。
>
> Schottky 续流二极管就是这条泄放路径——电流从地经过二极管流回线圈，安全释放能量。  
> 选 Schottky 而不是普通 PN 二极管，正是因为课程说的：反向恢复快（$t_{rr}$ 小）+ 正向压降低。TB6612 工作在 FPGA 发出的 **12.2kHz PWM** 下，每秒切换 12200 次，慢速二极管在这个频率下损耗会非常大。
>
> 简单理解：Schottky 续流 = 给电机线圈里的电流找一条"安全退路"。

---

#### TB6612 内部二极管数量

TB6612 驱动一个电机需要 4 个 MOSFET 组成 H 桥，每个 MOSFET 旁边并联一个 Schottky 续流二极管，两个通道共 **8 个**。这些二极管同时做两件事：

1. **续流**：给电感电流提供继续流动的路径
2. **钳压**：导通后电压被钳住，保护 MOSFET 不被反向尖峰击穿

两件事是同一个动作的两面——导通了电流就有路走，电压自然就钳住了。

#### 二极管深层物理机制（补充）

**耗尽层是什么**

PN 结接触后，N 区电子往 P 区扩散，P 区空穴往 N 区扩散，双方在结附近互相复合消失，形成一个**没有自由载流子的区域**，叫耗尽层。

耗尽层的方向：**沿电流方向只有很薄一层**（仅在 P 区和 N 区交界附近），但**横跨整个 PN 结面**，没有缺口，所以载流子无法绕过去。P 区和 N 区本身大部分都有自由载流子，不是整个都耗尽。

```
电流方向 I →

P区（空穴多）    耗尽层（自由载流子很少）    N区（电子多）
→→→→→→→→→→→  |░░░░░░░░░░░░|  →→→→→→→→→→→
→→→→→→→→→→→  |░░░░░░░░░░░░|  →→→→→→→→→→→
→→→→→→→→→→→  |░░░░░░░░░░░░|  →→→→→→→→→→→
              ↑
         薄的空间电荷区
         几乎没有自由载流子，但有固定离化离子，形成内建电场
         横跨整个 PN 结面，没有缺口
```

正向导通时，外加电压降低势垒，空穴和电子能够**跨越**结区——耗尽层不是像导线一样导电，而是势垒降低后载流子能穿过去。

**为什么反向加压才会击穿**

正向加压：外部电场与内建电场方向相反，互相抵消，耗尽层变薄，载流子顺利通过 → 导通。

反向加压：外部电场与内建电场同向叠加，耗尽层越来越宽，电场越来越强 → 高到某个值触发击穿。

类比平行板电容器：耗尽层厚度 = 极板间距 $d$，电场强度 $E = V/d$，$d$ 越小电场越强。

**掺杂程度影响耗尽层厚度**

- 轻掺杂：载流子少，扩散得远才达到平衡 → 耗尽层厚 → 同电压下电场弱
- 重掺杂（齐纳）：载流子多，扩散一点就平衡 → 耗尽层极薄 → 同电压下电场极强

齐纳二极管就是通过重掺杂让耗尽层极薄，从而在低电压（几伏）下就能产生足够强的电场触发**量子隧穿**（电子直接"穿墙"过去），不需要等到高电压雪崩。

**击穿为什么可逆**

击穿时硅原子本身没有被破坏，共价键结构完好，只是电子被踢出来变成自由载流子。撤掉电场后，电子重新被键抓住，结构恢复原状。

真正的损坏是**过热**：电流大 → 电子碰撞晶格 → 晶格振动加剧 → 温度升高 → 硅原子离开晶格位置 → 永久损坏。

所以齐纳不怕击穿本身，怕的是功耗超过额定值（通常 0.5W 或 1W）。串联限流电阻是必须的，没有它 → 电流无限大 → 烧毁。

**少数载流子存储与反向恢复时间 $t_{rr}$**

PN 二极管正向导通时，P 区空穴跑进 N 区，N 区电子跑进 P 区，双方载流子堆积在对方地盘附近。

突然反向电压时，这些堆积载流子还没消失，反向电流照样能流（这是"拖尾"，不是泄漏）。直到载流子复合消失，二极管才真正关断。这段时间就是 $t_{rr}$，普通 PN 约几微秒。

Schottky 靠金属-半导体结导电，没有少数载流子存储问题，$t_{rr}$ 只有几纳秒，快 1000 倍，因此适合 12.2kHz 这类高频切换场合。

```
电流波形（PN 二极管关断时）：

正向电流 ‾‾‾‾‾‾‾‾‾\
                   \
————————————————————\——————→ 时间
                     \‾‾‾|  ← 反向拖尾电流（堆积载流子在复合）
                         |__ 才真正截止
                     |←→|
                      trr
```

**齐纳稳压原理**

击穿后器件进入负阻区：电流增大但电压几乎不变。外电路限流电阻承担多余电压。

```
电源 12V → 限流电阻 Rs → 齐纳（5.1V）→ GND

无论电源在 8V~15V 之间变化，齐纳两端始终 5.1V
多余电压全部降在 Rs 上
```

**各类二极管对比速查**

| 类型 | 正向压降 | $t_{rr}$ | 典型用途 |
|------|---------|---------|---------|
| 普通 PN | 0.6~0.7V | 几微秒 | 低频整流 |
| Schottky | 0.2~0.3V | 几纳秒 | 高频续流、DC-DC |
| 齐纳 | — | — | 稳压、钳位 |
| TVS | — | 皮秒级 | ESD/瞬态保护 |
| 快恢复 | 0.6~0.7V | 几百纳秒 | 中频场合 |

### 1.2 BJT（双极型晶体管）

BJT 可以作为放大器，也可以作为开关。功率管理中更多关注其开关行为。

#### 三个工作区

| 工作区 | 条件 | 用途 |
|---|---|---|
| Cut-off 截止区 | BE 结未导通 | 开关断开 |
| Active 放大区 | BE 正偏，BC 反偏 | 线性放大 |
| Saturation 饱和区 | BE、BC 均正偏 | 开关闭合 |

#### 作为开关使用

为了让 BJT 饱和，需要提供足够的基极电流：

\[
I_B \geq \frac{I_C}{\beta_{\text{forced}}}
\]

其中 \(\beta_{\text{forced}}\) 通常取比实际电流增益更小的值，例如 \(5\sim10\)，以确保晶体管进入饱和。

#### 饱和导通特点

| 参数 | 含义 |
|---|---|
| \(V_{BE(on)}\) | BJT 开始导通所需的 BE 电压 |
| \(V_{CE(sat)}\) | 饱和时 CE 压降，常见约 \(0.1\sim0.3\text{ V}\) |
| \(V_{BE(sat)}\) | 饱和时 BE 压降 |

#### 关断问题

BJT 饱和时会在基区存储电荷，因此关断需要时间。为了加快关断，可采用：

- 增大瞬态反向基极电流；
- 使用动态基极驱动；
- 避免晶体管深饱和；
- 使用 Baker clamp 限制 BC 结正偏。

#### Darlington Transistor

Darlington 管由两个 BJT 复合而成。

优点：

- 电流增益高；
- 对基极驱动电流要求低。

缺点：

- 导通压降更高；
- 开关速度更慢；
- 饱和压降通常比单个 BJT 大。

> **[项目对照] 为什么电机驱动用 MOSFET 而不是 BJT/Darlington？**
>
> 早期电机驱动芯片（比如 L298N）内部用的就是 BJT/Darlington。但你项目里选的 **TB6612FNG** 内部用的是 MOSFET，原因正是 Darlington 的两个缺点在高频 PWM 场景下非常致命：
>
> 1. **导通压降更高**：L298N 每个 H 桥臂导通压降约 2V，12V 供电直接损失掉 4V（上下各 2V），效率很差。TB6612 的 MOSFET 版本压降约 0.5V，损耗小得多。
> 2. **开关速度更慢**：12.2kHz 下 BJT 的存储电荷来不及清除，会导致热量积累和波形失真。MOSFET 没有少数载流子，关断快。
>
> 结论：**高频 PWM + 电机控制 → 优先选 MOSFET H 桥（TB6612 这类），不选 BJT H 桥（L298N 这类）**。

### 1.3 MOSFET

MOSFET 是功率开关电源中最常见的开关器件。

#### 工作区

| 工作区 | 条件 | 用途 |
|---|---|---|
| Cut-off 截止区 | \(V_{GS}<V_{th}\) | 关断 |
| Triode / Linear 区 | \(V_{GS}>V_{th}\)，且 \(V_{DS}\) 较小 | 开关导通，近似电阻 |
| Saturation 饱和区 | \(V_{DS}\) 较大 | 放大或电流源状态 |

功率 MOSFET 作为开关时，应尽量让其：

- 关断时进入 cut-off；
- 导通时进入 triode 区，使其表现为低阻开关。

#### 关键参数

| 参数 | 含义 |
|---|---|
| \(V_{DS,max}\) | 最大漏源耐压 |
| \(I_D\) | 最大漏极电流 |
| \(R_{DS(on)}\) | 导通电阻 |
| \(P_{max}\) | 最大功耗 |
| \(Q_g\) | 栅极电荷，影响驱动速度和开关损耗 |
| \(V_{GS(th)}\) | 栅源阈值电压 |

#### 导通损耗

\[
P_{\text{cond}} = I_D^2R_{DS(on)}
\]

#### 栅极驱动重点

MOSFET 的栅极稳态电流很小，但栅极等效为电容。高频开关时需要反复给栅极电容充放电，因此需要 gate driver 提供较大的瞬态电流。

> **[项目对照] TB6612 内部 MOSFET 的导通损耗**
>
> TB6612 内部四个 MOSFET 的 $R_{DS(on)}$ 典型值约为 **0.5Ω（高边）+ 0.5Ω（低边）**，合计约 1Ω。
>
> 空载时电机电流约 30mA，导通损耗：
> $$P_{cond} = I^2 \times R_{DS(on)} = (0.03)^2 \times 1 \approx 0.9 \text{ mW}$$
> 这很小，可以忽略。
>
> 但如果带载电流上升到 500mA（额定范围内），损耗就变成：
> $$P_{cond} = (0.5)^2 \times 1 = 250 \text{ mW}$$
> 芯片开始明显发热。这就是为什么 TB6612 的最大连续电流规格是 1.2A——超过后 MOSFET 热损耗超过芯片散热能力。
>
> **栅极驱动**：TB6612 的 PWM 输入来自 FPGA（12.2kHz），芯片内部集成了 gate driver，你不需要额外设计驱动电路——这正是 TB6612 相比分立 MOSFET 方案的优点。

## 2. 负载驱动方式

### 2.1 Low-side 驱动

Low-side switch 的结构：

```text
VDD → Load → Switch → GND
```

常见器件：

- NPN BJT；
- NMOS。

#### 优点

- 电路简单；
- 控制信号以地为参考，容易驱动；
- NMOS 的 \(R_{DS(on)}\) 通常较低；
- 适合多数低边开关场景。

#### 缺点

- 负载不直接接地；
- 某些系统中可能不允许负载端悬浮；
- 如果负载端必须固定接地，则 low-side 不合适。

---

### 2.2 High-side 驱动

High-side switch 的结构：

```text
VDD → Switch → Load → GND
```

#### High-side PNP / PMOS

使用 PNP 或 PMOS 做高边开关时，驱动相对简单。

缺点：

- PNP / PMOS 性能通常弱于 NPN / NMOS；
- 导通电阻或压降通常更大；
- 大电流场景下损耗较高。

#### High-side NMOS 的难点

如果 NMOS 做高边开关，当源极电压接近 \(V_{DD}\) 时，要继续导通需要：

\[
V_G > V_S + V_{th}
\]

也就是说，栅极电压可能要高于电源电压。

#### 常用解决方案

| 方法 | 作用 |
|---|---|
| Charge Pump | 产生高于 \(V_{DD}\) 的栅极驱动电压 |
| Bootstrap Driver | 半桥、全桥中常用 |
| Level Shifter | 将低压逻辑信号转换为高边参考信号 |
| PMOS High-side | 简化驱动，但效率和性能较差 |

---

### 2.3 Floating Load

当负载两端都不固定接地时，可以使用半桥或全桥驱动。

---

### 2.4 Half-bridge

Half-bridge 由一个高边开关和一个低边开关组成。

```text
       VDD
        |
   High-side Switch
        |
      Output
        |
   Low-side Switch
        |
       GND
```

#### 输出状态

| 高边开关 | 低边开关 | 输出 |
|---|---|---|
| ON | OFF | 接近 \(V_{DD}\) |
| OFF | ON | 接近 GND |
| OFF | OFF | Floating |
| ON | ON | 短路，禁止 |

> **[项目对照] TB6612 内部有两个 Half-bridge**
>
> TB6612FNG 驱动一路电机需要两个 Half-bridge 合成一个 Full H-bridge（见下节）。  
> 芯片内部的 STBY 引脚 = 让所有 MOSFET 全部进入截止区（OFF/OFF 状态），相当于电机自由旋转（惰行），而不是强制刹车。
>
> 你的代码中 STBY 接 STM32 一个 GPIO，上电后拉高使能，停机时拉低让电机惰行。

---

### 2.5 Full H-bridge

Full H-bridge 由两个 half-bridge 构成，可使负载两端电压反向。

#### 工作状态

| 状态 | 导通开关 | 负载电压 |
|---|---|---|
| 正向 | 左上 + 右下 | 正向 |
| 反向 | 右上 + 左下 | 反向 |
| 悬空 | 全部关断 | Floating |
| 短路 | 同一桥臂上下同时导通 | 禁止 |

#### 重点

- H 桥常用于电机正反转控制；
- 必须避免 shoot-through；
- 实际驱动中常加入 dead time。

> **[项目对照] TB6612FNG = 集成 Full H-bridge 芯片**
>
> 课程里 Full H-bridge 需要 4 个开关管。TB6612 把这一切集成在一颗芯片里，接口简化成三个信号：
>
> | 信号 | 来自 | 作用 |
> |---|---|---|
> | AIN1 / AIN2 | STM32 GPIO | 控制左上+右下（正转）还是右上+左下（反转） |
> | PWMA | FPGA J3-31 | PWM 占空比，控制电机转速（0~4095 → 0%~100%） |
> | STBY | STM32 GPIO | 拉低=全部关断（惰行），拉高=使能工作 |
>
> **Shoot-through 防护**：TB6612 内部硬件保证同一桥臂不会同时导通，你不需要在代码里写 dead time——这是集成驱动 IC 相比分立方案的核心优点。
>
> **工作流程**（正转 + 50% 转速为例）：
> 1. STM32 设置 AIN1=1, AIN2=0（正转方向）
> 2. FPGA 输出 PWM，占空比 50%（duty=2048/4095）
> 3. TB6612 内部：每个 PWM 周期高电平时"左上+右下"导通，低电平时续流二极管接管
> 4. 电机两端平均电压 ≈ 12V × 50% = 6V → 对应约 50RPM

## 3. 电源基础指标

### 3.1 Load Regulation（负载调整率）

表示负载电流变化时输出电压变化的程度：

\[
S_I = R_{out} = \frac{\Delta V_{out}}{\Delta I_{out}}
\]

越小越好。

---

### 3.2 Line Regulation（线性调整率）

表示输入电压变化时输出电压变化的程度：

\[
S_V = \frac{\Delta V_{out}}{\Delta V_{in}}
\]

越小越好。

---

### 3.3 Efficiency（效率）

\[
\eta = \frac{P_{out}}{P_{in}}
\]

#### 线性稳压与开关稳压对比

| 类型 | 优点 | 缺点 |
|---|---|---|
| Linear Regulator | 输出干净、纹波小、设计简单 | 效率低，发热大 |
| Switching Regulator | 效率高，可升压/降压/反相 | 控制复杂，有噪声和 EMI |

> **[项目对照] PWM 调速 vs 线性调压 的效率对比**
>
> 如果不用 PWM，而是用线性方式控制电机转速（比如在电机串联一个可变电阻），效率会极差：
>
> 假设要让电机以 50% 转速运行（约 6V），用线性调压：
> $$\eta_{linear} \approx \frac{V_{out}}{V_{in}} = \frac{6}{12} = 50\%$$
> 另外 6V 全部变成热量在调节元件上耗散。
>
> 用 FPGA PWM 调速（本质是开关稳压）：理想情况下效率接近 100%（只有 MOSFET 导通损耗和续流二极管损耗，一般 > 90%）。
>
> **这就是为什么电机控制一律用 PWM 而不用线性调压**——在你项目里，FPGA 生成 12.2kHz PWM 传给 TB6612，就是在做高效率的开关调速。

## 4. 整流与滤波

### 4.1 Rectifier（整流器）

整流器将 AC 转换为脉动 DC。

---

### 4.2 Half-wave Rectifier（半波整流）

半波整流只利用交流波形的一半。

#### 特点

- 电路简单；
- 只有半个周期导通；
- 纹波大；
- 变压器利用率低；
- 滤波电容需要更大。

---

### 4.3 Full-wave Rectifier（全波整流）

全波整流利用交流波形的两个半周期。

#### 常见形式

1. 中心抽头变压器 + 2 个二极管；
2. 桥式整流 + 4 个二极管。

#### 桥式整流特点

- 每次有两个二极管导通；
- 导通压降约为 \(2V_f\)；
- 不需要中心抽头变压器；
- 变压器利用率较高。

---

### 4.4 Maximum Reverse Voltage（二极管最大反向电压）

选择整流二极管时必须保证：

\[
V_{BR} > V_{\text{reverse,max}}
\]

一般规律：

- 半波整流和中心抽头全波整流中，二极管反向耐压要求较高；
- 桥式整流中，单个二极管承受的最大反向电压通常较低；
- 实际设计中要留安全裕量。

---

### 4.5 Filter（滤波）

整流输出是脉动电压，需要电容滤波得到近似 DC。

#### 电容纹波近似

\[
\Delta V \approx \frac{I_{load}\Delta t}{C}
\]

其中：

- \(I_{load}\)：负载电流；
- \(\Delta t\)：电容放电时间；
- \(C\)：滤波电容。

#### 结论

- 电容越大，纹波越小；
- 负载电流越大，纹波越大；
- 全波整流的纹波频率是半波整流的 2 倍；
- 全波整流所需电容通常小于半波整流；
- 纹波越小，二极管导通时间越短，峰值电流越大。

> **[项目对照] 电容滤波在项目中的两处应用**
>
> 虽然你不需要自己做整流电路（12V 适配器内部已经完成），但同样的 RC 滤波思想出现在两个地方：
>
> **① 电位器输入滤波（PA0）**  
> 旋钮电位器输出的是模拟电压，但机械接触和线路噪声会引入毛刺。在 PA0 前加了 RC 低通滤波器（电阻 + 电容），作用和课程的滤波电容一样：电容把快速变化的噪声"平滑"掉，只让缓慢变化的转速给定信号通过。
>
> **② 电流采样滤波（PA1）**  
> INA240 输出的电流信号在 PWM 开关边沿会有尖峰（因为 MOSFET 开关时电流瞬变）。软件里对 PA1 做 **8点滑动平均**，原理等效于一个数字低通滤波器，抑制 PWM 开关引起的电流测量噪声。

## 5. 线性稳压器

### 5.1 Linear Regulator 基本思想

线性稳压器通过串联调整元件消耗多余电压，使输出保持稳定。

#### 为什么效率低

调节管（BJT 或 MOSFET）工作在**线性区（放大区）**，相当于一个**可变电阻**，多余电压全部在它身上变成热耗散掉：

```
Vin ──[调节管（可变电阻）]──── Vout
              ↑
         压降 = Vin - Vout
         功耗 = (Vin - Vout) × I
         全部变热，无法回收
```

输入电压变化时，调节管自动调整阻值保证输出不变：

```
Vin 升高 → 调节管电阻变大 → 多吸收电压 → Vout 不变
Vin 降低 → 调节管电阻变小 → 少吸收电压 → Vout 不变
```

叫"线性"稳压正是因为调节管工作在线性区，而不是像开关稳压那样工作在开/关两个极端。

对比开关稳压：

```
线性稳压：多余电压 → 调节管变热（浪费）
开关稳压：多余能量 → 存入电感/电容 → 再释放给负载（不浪费）
```

#### 基本特点

- 输出噪声低；
- 负载调整率好；
- 线性调整率好；
- 效率低，尤其当 \(V_{in}\) 远高于 \(V_{out}\) 时。

#### 效率近似

若忽略静态电流：

\[
\eta \approx \frac{V_{out}}{V_{in}}
\]

---

### 5.2 Zener Linear Regulator

基本结构：

```text
Vin → Rs → Vout
          |
        Zener
          |
         GND
```

#### 输出电压

理想情况下：

\[
V_{out} \approx V_Z
\]

#### 串联电阻电流

\[
I_R = \frac{V_{in}-V_Z}{R_S}
\]

并且：

\[
I_R = I_Z + I_{load}
\]

#### 设计约束 1：最低输入、最大负载

需要保证 Zener 仍在击穿区：

\[
I_Z \geq I_{Z,min}
\]

因此：

\[
\frac{V_{in,min}-V_Z}{R_S} - I_{load,max} \geq I_{Z,min}
\]

#### 设计约束 2：最高输入、最小负载

需要保证 Zener 不过功率：

\[
P_Z = V_Z I_Z \leq P_{Z,max}
\]

其中：

\[
I_Z = \frac{V_{in,max}-V_Z}{R_S} - I_{load,min}
\]

#### 缺点

- 效率低；
- 输出电流能力弱；
- 稳压精度受 Zener 动态电阻影响；
- 负载变化大时性能较差。

---

### 5.3 BJT Pass Transistor Regulator

在 Zener 后加入 BJT，可提升输出电流能力。

#### 输出电压近似

\[
V_{out} \approx V_Z - V_{BE}
\]

#### 优点

- Zener 只需提供较小基极电流；
- BJT 承担主要负载电流；
- 输出电阻降低；
- 负载调整率改善。

#### 缺点

- 仍然是线性稳压，效率低；
- 需要满足输入输出压差；
- BJT 有功耗和散热问题。

---

### 5.4 三端稳压器

三端稳压器内部集成参考源、误差放大器、功率管和保护电路。

#### 特点

- 使用简单；
- 输出稳定；
- 负载调整率好；
- 线性调整率好；
- 需要满足 dropout voltage；
- 效率仍然受 \(V_{out}/V_{in}\) 限制。

#### 总结

线性稳压器输出质量好，但效率低。

> **[项目对照] 面包板电源模块 = 三端稳压器**
>
> 你项目里给 STM32 和 OLED 供电的**面包板电源模块**（MB102），内部用的就是 LM7805（5V）和 LM1117（3.3V）这类三端稳压器。
>
> 输入：12V 适配器 → 三端稳压器 → 输出 3.3V（给 STM32 和 OLED）
>
> 效率计算：
> $$\eta \approx \frac{V_{out}}{V_{in}} = \frac{3.3}{12} \approx 27.5\%$$
>
> 另外 72.5% 的能量在稳压芯片里变成了热量——这就是为什么面包板电源模块带大电流时会烫手。
>
> 好消息：STM32 + OLED 的总电流很小（~100mA 以内），实际损耗 $P = (12-3.3) \times 0.1 \approx 0.87\text{W}$，还在可接受范围。

## 6. 开关电源基础

### 6.1 Switching Power Supply 基本思想

开关电源通过高速开关控制电感和电容的能量转移，再通过反馈调节占空比来稳定输出。

#### 核心组成

- 开关管；
- 二极管或同步整流管；
- 电感或变压器；
- 输出电容；
- PWM 控制器；
- 反馈网络。

#### 优点

- 效率高；
- 可实现降压、升压、反相、隔离；
- 适合大功率应用。

#### 缺点

- 控制复杂；
- 有开关纹波；
- 有 EMI 问题；
- 元件选择和布局更关键。

## 7. Buck Converter（降压型 DC-DC）

### 7.1 功能

Buck 用于降压：

\[
V_{out}<V_{in}
\]

---

### 7.2 CCM 下的理想关系

连续导通模式 CCM 下：

\[
V_{out} = D V_{in}
\]

其中 \(D\) 是占空比。

---

### 7.3 工作过程

#### 开关 ON

- MOSFET 导通；
- 二极管截止；
- 电感电流上升；
- 电感储能。

电感电压：

\[
V_L = V_{in}-V_{out}
\]

电流变化：

\[
\Delta I_{L,on} = \frac{V_{in}-V_{out}}{L}DT
\]

#### 开关 OFF

- MOSFET 关断；
- 二极管续流；
- 电感电流下降；
- 电感向负载释放能量。

电感电压：

\[
V_L = -V_{out}
\]

电流变化：

\[
\Delta I_{L,off} = -\frac{V_{out}}{L}(1-D)T
\]

---

### 7.4 伏秒平衡

稳态下，电感一个周期内平均电压为零：

\[
(V_{in}-V_{out})DT + (-V_{out})(1-D)T = 0
\]

整理得到：

\[
V_{out}=DV_{in}
\]

---

### 7.5 电感电流纹波

\[
\Delta I_L = \frac{(V_{in}-V_{out})DT}{L}
\]

也可以写成：

\[
\Delta I_L = \frac{V_{out}(1-D)T}{L}
\]

---

### 7.6 CCM / DCM

#### CCM

电感电流始终大于零：

\[
I_{L,min}>0
\]

#### DCM

电感电流在一个周期内降到零：

\[
I_{L,min}=0
\]

#### 区别

| 模式 | 特点 |
|---|---|
| CCM | 输出电压主要由 \(D\) 和 \(V_{in}\) 决定 |
| DCM | 输出电压还与负载、电感、频率有关 |

---

### 7.7 设计重点

- 电感电流额定值应大于最大峰值电流；
- 电容要满足纹波电压要求；
- 二极管或同步管要满足电流和耐压；
- MOSFET 要满足电流、耐压、功耗与开关速度。

> **[项目对照] PWM 电机调速 ≈ 一个 Buck Converter**
>
> 这是整节课和你项目最有趣的对应关系。
>
> Buck Converter 的核心公式是：
> $$V_{out} = D \times V_{in}$$
>
> 你的 PWM 电机控制，本质上做的是完全相同的事情：
> $$V_{motor,avg} = D \times V_{supply} = D \times 12\text{V}$$
>
> 其中 $D$ 就是 FPGA 输出的 PWM 占空比（duty/4095）。
>
> | Buck Converter | 你的电机调速系统 |
> |---|---|
> | 输入电压 $V_{in}$ | 12V 电源 |
> | 占空比 $D$（0~1） | duty / 4095（0~4095） |
> | 输出电压 $V_{out}$ | 电机两端平均电压 |
> | 电感 | 电机线圈（本身就是电感！） |
> | 续流二极管 | TB6612 体二极管 |
> | 输出电容 | 电机的机械惯量（起到"平滑"作用） |
>
> **最关键的类比**：电机线圈本身就是电感，所以 TB6612 + 电机的组合，天然构成了一个没有额外电感的简化 Buck 拓扑。电机转速对应 Buck 的"输出电压"，PID 控制器相当于 PWM 控制器。
>
> 所以你的项目不是"用 PWM 控制电机"，更准确地说是"用 H 桥实现的 Buck 变换器驱动电感性负载（电机）"。

---

## 8. Boost Converter（升压型 DC-DC）

### 8.1 功能

Boost 用于升压：

\[
V_{out}>V_{in}
\]

---

### 8.2 CCM 下的理想关系

\[
V_{out} = \frac{V_{in}}{1-D}
\]

---

### 8.3 工作过程

#### 开关 ON

- MOSFET 导通；
- 二极管反偏；
- 电感接在输入端；
- 电感电流上升；
- 输出由电容供电。

电感电压：

\[
V_L = V_{in}
\]

电流变化：

\[
\Delta I_{L,on} = \frac{V_{in}}{L}DT
\]

#### 开关 OFF

- MOSFET 关断；
- 二极管导通；
- 电感与输入共同向输出供能；
- 电感电流下降。

电感电压：

\[
V_L = V_{in}-V_{out}
\]

电流变化：

\[
\Delta I_{L,off} = \frac{V_{in}-V_{out}}{L}(1-D)T
\]

---

### 8.4 伏秒平衡

\[
V_{in}DT + (V_{in}-V_{out})(1-D)T = 0
\]

整理得到：

\[
V_{out}=\frac{V_{in}}{1-D}
\]

---

### 8.5 特点

- \(D\) 越大，输出电压越高；
- 当 \(D\to1\) 时，理论输出趋于无穷大，但实际会受损耗、电流限制和控制稳定性限制；
- 输入电流连续；
- 输出电流脉动；
- Boost 的开环输出对负载和输入变化更敏感，通常必须使用闭环控制。

---

## 9. Buck-Boost Converter（反相升降压）

### 9.1 功能

Buck-Boost 可实现：

- 升压；
- 降压；
- 输出极性反相。

---

### 9.2 CCM 下的理想关系

\[
V_{out} = -\frac{D}{1-D}V_{in}
\]

负号表示输出极性与输入相反。

---

### 9.3 工作过程

#### 开关 ON

- MOSFET 导通；
- 二极管反偏；
- 电感由输入供能；
- 电感电流上升；
- 负载由输出电容供电。

电感电压：

\[
V_L = V_{in}
\]

#### 开关 OFF

- MOSFET 关断；
- 二极管导通；
- 电感向输出释放能量；
- 电感电流下降。

电感电压：

\[
V_L = V_{out}
\]

由于 \(V_{out}\) 为负，因此电感电流下降。

---

### 9.4 伏秒平衡

\[
V_{in}DT + V_{out}(1-D)T = 0
\]

整理得到：

\[
V_{out}=-\frac{D}{1-D}V_{in}
\]

---

### 9.5 特点

- 输出电压极性反相；
- 可升压也可降压；
- 输出电流是脉动的；
- 输出电容纹波压力较大；
- 当占空比较高时，输入侧电流和器件应力较大。

---

## 10. Flyback Converter（反激变换器）

### 10.1 基本理解

Flyback 可以看作带变压器隔离的 Buck-Boost。

严格来说，Flyback 中的变压器更像耦合电感：

- 开关导通时，能量储存在磁芯中；
- 开关关断时，能量传递到副边输出。

---

### 10.2 特点

- 可实现输入输出隔离；
- 可实现升压或降压；
- 可通过多个副边绕组产生多路输出；
- 常用于中小功率电源适配器；
- 通常适合 low-side switch 驱动。

---

## 11. 闭环调节 Regulator Circuit

### 11.1 为什么需要闭环

开环 DC-DC 的输出会受到以下因素影响：

- 输入电压变化；
- 负载电流变化；
- 器件损耗；
- 电感电阻和二极管压降；
- 温度变化。

因此实际电源通常使用反馈闭环控制。

---

### 11.2 基本结构

闭环稳压系统包括：

1. 输出电压采样；
2. 与参考电压比较；
3. 误差放大；
4. PWM 比较；
5. 改变占空比；
6. 调整输出电压。

---

### 11.3 反馈分压

若输出电压通过分压电阻采样：

```text
Vout → R2 → Vsense → R1 → GND
```

则：

\[
V_{sense}=\frac{R_1}{R_1+R_2}V_{out}
\]

闭环稳定时：

\[
V_{sense}=V_{ref}
\]

因此：

\[
V_{out}=V_{ref}\frac{R_1+R_2}{R_1}
\]

---

### 11.4 PWM 控制

误差放大器输出与锯齿波或三角波比较，生成 PWM 信号。

- 误差电压升高，占空比增大；
- 误差电压降低，占空比减小；
- 占空比变化后，输出电压随之调整。

> **[项目对照] 串级 PID = 课程闭环框架的推广**
>
> 课程 §11 讲的闭环稳压（稳定输出电压）和你的电机串级 PID（稳定转速）是**完全相同的控制框架**，只是被控量不同：
>
> **课程闭环稳压对应关系：**
>
> | 课程组件 | 你的项目（速度外环） | 你的项目（电流内环） |
> |---|---|---|
> | 参考电压 $V_{ref}$ | 目标转速（电位器 PA0） | 速度 PID 输出（目标电流） |
> | 采样反馈 | TIM3 编码器实测 RPM | INA240 采样实测电流 |
> | 误差 = ref - feedback | RPM 误差 | 电流误差 |
> | 误差放大器 | 速度 PID 计算（kp=1.5, ki=0.1） | 电流 PID 计算（kp=5.0, ki=0.2） |
> | PWM 比较器 | 输出目标电流（0~400mA） | 输出 duty（0~4095） |
> | 被控对象 | 电机+驱动系统 | TB6612 + 电机电流响应 |
>
> **为什么用串级（两个闭环）而不是一个？**
>
> 一个闭环（只控速度）的问题：速度变化很慢（机械惯性大），但电流变化很快（电气响应快）。如果只有速度环，当负载突变时，电流可能在速度环还没反应过来之前就已经烧毁电机线圈。
>
> 内环（电流环）负责快速保护：每 1ms 检查一次电流，把电流锁定在速度环给定的安全范围内。  
> 外环（速度环）负责慢速调节：每 1ms 检查一次转速，告诉内环"目标电流该是多少"。
>
> 类比：外环是"导航"（告诉你要去哪），内环是"油门控制"（精确控制每一步的力度）。

**串级 PID 从0到目标转速的动态过程（以100RPM为例）：**

第1ms（刚上电）：
```
目标RPM=100，实际RPM=0，速度误差=100
速度PID：误差大 → 目标电流=400mA（上限）
电流PID：误差大 → duty≈3000/4095（73%占空比）
电机开始加速
```

加速阶段（10~50ms）：
```
实际RPM从0慢慢上升，速度误差还大
目标电流维持在400mA上限
duty稳定在较高位置，电机持续加速
```

接近目标（100~200ms）：
```
实际RPM接近100，速度误差变小
目标电流开始下降（比如150mA）
duty下降，电机加速度减小，转速趋于平稳
```

稳定后：
```
实际RPM≈100，速度误差≈0
目标电流=维持转速所需小电流（空载约30mA）
duty≈200/4095（很低），电机匀速转动
```

**启动时duty高，稳定后duty低**——类比开车，起步油门深，巡航油门轻：
```
启动时：duty≈3000/4095 → 平均电压≈8.8V → 大力加速
稳定后：duty≈200/4095  → 平均电压≈0.6V → 只克服摩擦力维持转速
```

带负载时稳定后的duty会更高，因为需要更多力矩对抗负载阻力。

中途加负载时（串级PID优势）：
```
实际RPM突然从100降到80
速度误差变大 → 目标电流增大
电流内环快速响应 → duty增大 → 补充转矩
实际RPM恢复到100
```
电流内环响应极快，在速度还没明显下降之前就已经补充电流了。

速度外环和电流内环的分工：
```
速度外环 → 输出"目标电流"（不直接控制PWM）
电流内环 → 拿到目标电流 → 输出duty值 → 控制PWM
```
两个环每1ms都同时运行，不需要等反馈才启动——反馈是用来修正的，不是用来启动的。速度外环输出的目标电流有限幅（0~400mA），防止积分累积导致输出飞掉（anti-windup）。

**PWM 是"穷人版 DAC"：**

真正的 DAC 输出连续模拟电压，PWM 靠电感平滑实现等效平均电压，对电机效果一样但效率远高于 DAC：

| | 真DAC | PWM |
|---|---|---|
| 输出 | 真正的连续电压 | 高速开关的平均值 |
| 效率 | 低（类似线性稳压） | 高（类似开关稳压） |
| 实现 | 需要DAC外设 | 定时器+MOSFET即可 |
| 噪声 | 干净 | 有开关纹波 |

选 PWM 而不是 DAC 控制电机，原因和选开关稳压而不选线性稳压一样——效率高。
>
> **TIM6 1kHz 中断执行顺序（每 1ms 一次）：**
> ```
> 读 ADC（电流） → 读编码器（转速）
>   → 速度 PID → 得到目标电流
>     → 电流 PID → 得到 duty 值
>       → SPI2 发送 duty → FPGA 更新 PWM
> ```
> 整个过程约 9μs，占 1ms 周期的 0.9%，CPU 利用率极低。

> ↓

> ↓
> 开关调速（PWM = 简化 Buck，V_motor = D × 12V）

## 13. 公式速查表

| 模块 | 公式 | 含义 |
|---|---|---|
| 效率 | \(\eta=\frac{P_{out}}{P_{in}}\) | 输出功率与输入功率之比 |
| 负载调整率 | \(S_I=\frac{\Delta V_{out}}{\Delta I_{out}}\) | 负载变化对输出电压的影响 |
| 线性调整率 | \(S_V=\frac{\Delta V_{out}}{\Delta V_{in}}\) | 输入变化对输出电压的影响 |
| 电容纹波 | \(\Delta V\approx\frac{I_{load}\Delta t}{C}\) | 滤波电容纹波估算 |
| 线性稳压效率 | \(\eta\approx\frac{V_{out}}{V_{in}}\) | 忽略静态电流时 |
| Buck | \(V_{out}=DV_{in}\) | 降压 |
| Boost | \(V_{out}=\frac{V_{in}}{1-D}\) | 升压 |
| Buck-Boost | \(V_{out}=-\frac{D}{1-D}V_{in}\) | 反相升降压 |
| 反馈输出 | \(V_{out}=V_{ref}\frac{R_1+R_2}{R_1}\) | 分压反馈设定输出 |

## 14. 复习重点

### 器件部分

- Diode：
  - \(V_f\)、\(V_{BR}\)、\(t_{rr}\)、Schottky 特性。
- BJT：
  - 截止、放大、饱和；
  - 强迫 \(\beta\)；
  - 饱和存储电荷；
  - 基极驱动设计。
- MOSFET：
  - \(V_{GS}\)、\(V_{th}\)、\(R_{DS(on)}\)；
  - 栅极电荷；
  - 高边 NMOS 驱动难点。

### 驱动部分

- Low-side 最简单；
- High-side NMOS 需要 charge pump / bootstrap / level shifter；
- H 桥可实现负载双向驱动；
- 必须避免 shoot-through。

### 电源部分

- 整流后必须滤波；
- 半波整流纹波大；
- 全波整流效率和纹波更好；
- 电容越大，纹波越小，但二极管峰值电流可能更大。

### 稳压部分

- Zener 稳压简单但性能有限；
- BJT pass transistor 可增强电流能力；
- 三端稳压器简单可靠；
- 线性稳压器输出好但效率低。

### 开关电源部分

- Buck：降压；
- Boost：升压；
- Buck-Boost：反相升降压；
- Flyback：隔离型、类似带变压器的 Buck-Boost；
- 实际 DC-DC 通常需要闭环反馈控制。

## 15. 电机驱动深入理解（结合 TB6612 项目）

### 15.1 为什么需要电机驱动芯片

STM32 GPIO 最大输出 25mA、3.3V，电机需要 12V、几百毫安到几安。电机驱动芯片的作用是**用小信号控制大功率**——本质是功率放大器。

### 15.2 H 桥 = 两个半桥的组合

H 桥由左右各一个半桥组成，每个半桥包含一个高边 MOSFET 和一个低边 MOSFET，电机挂在两个半桥的中间节点之间：

```
        VM(12V)
           |
    [Q1]        [Q3]     ← 高边（连接12V）
      |              |
     AO1←←←M→→→AO2      ← 电机接在中间
      |              |
    [Q2]        [Q4]     ← 低边（连接GND）
           |
          GND

左半桥：Q1（高边）+ Q2（低边）
右半桥：Q3（高边）+ Q4（低边）
```

H 桥和 CMOS 反相器结构完全相同（上P/PMOS + 下N/NMOS），区别只是电压和电流量级不同——H 桥是**功率版 CMOS**。

### 15.3 H 桥的作用：正转/反转/刹车/惰行

H 桥解决的核心问题是让电机能**正转也能反转**——靠改变流过电机的电流方向实现，物理本质是安培力方向随电流方向改变。

```
正转：Q1+Q4 导通（左高边+右低边对角线）
      电流：12V → Q1 → AO1 → 电机 → AO2 → Q4 → GND

反转：Q3+Q2 导通（右高边+左低边对角线）
      电流：12V → Q3 → AO2 → 电机 → AO1 → Q2 → GND
```

| Q1 | Q2 | Q3 | Q4 | 结果 |
|----|----|----|-----|------|
| ✓ | ✗ | ✗ | ✓ | 正转 |
| ✗ | ✓ | ✓ | ✗ | 反转 |
| ✗ | ✗ | ✗ | ✗ | 惰行 |
| ✗ | ✗ | ✓ | ✓ | 刹车（两端同时接GND） |

同一侧高边和低边绝对不能同时导通（shoot-through），否则 12V 直接对 GND 短路。TB6612 内部硬件防止这种情况。

### 15.4 TB6612 各引脚含义

**Q1-Q4 在芯片内部，封装看不到。** 对外暴露的引脚：

**电源类**

| 引脚 | 接到 | 作用 |
|------|------|------|
| VCC | 3.3V | 给芯片内部逻辑电路供电（控制信号识别、栅极驱动） |
| VM | 12V | 给电机供电，路过芯片经H桥后从AO1/AO2流出 |
| GND | 共地 | VCC 和 VM 的地接在一起 |

> VCC = 给芯片自己运转的电；VM = 路过芯片流向电机的电，两者分开是因为控制逻辑只需要低压小电流，电机需要高压大电流，分开互不干扰。

**控制类**

| 引脚 | 接到（本项目） | 作用 |
|------|--------------|------|
| AIN1 | 3.3V（固定高） | 方向控制，和 AIN2 组合决定哪对 MOSFET 导通 |
| AIN2 | GND（固定低） | AIN1=1,AIN2=0 → 正转；AIN1=0,AIN2=1 → 反转 |
| PWMA | FPGA J3-31 | PWM 输入，占空比控制转速 |
| STBY | 3.3V（固定高） | 低=全部MOSFET关断待机；高=芯片正常工作 |

> AIN1/AIN2 接到 Q1-Q4 的栅极，决定哪条对角线通。在图中看不到，是芯片内部逻辑。

**输出类**

| 引脚 | 接到 | 作用 |
|------|------|------|
| AO1 | 电机一端 | 左半桥中间节点（Q1 和 Q2 之间） |
| AO2 | 电机另一端 | 右半桥中间节点（Q3 和 Q4 之间） |

完整电流路径：
```
12V → VM → 芯片内部H桥 → AO1 → 电机 → AO2 → 芯片内部H桥 → GND
```

### 15.5 PWM 调速分工

AIN1/AIN2 和 PWMA 各管一件事：

```
AIN1/AIN2 = 拨档（选方向，决定哪条对角线通）
PWMA      = 油门（在选定方向上控制转速）
```

PWM 永远控制**当前导通的低边 MOSFET**：

```
正转时：Q1 高边固定导通，Q4 低边跟着 PWMA 高速开关
反转时：Q3 高边固定导通，Q2 低边跟着 PWMA 高速开关
```

高边固定导通不做 PWM，是因为高边 MOSFET 驱动复杂（源极不接GND，栅极需要高于VM的电压），不适合高频切换。

**Q4 开关时电机发生什么：**

```
Q4 导通 → 12V 经 Q1→AO1→电机→AO2→Q4→GND，供能，电流上升
Q4 关断 → 供能路径断开，但电机是电感，电流不能瞬间为零
         → 续流二极管导通，电流继续绕圈，电机靠惯性转
Q4 再导通 → 重新供能...

12.2kHz 高速重复 → 电流维持平均值 → 对应平均转速
占空比越大 → 平均电流越大 → 转越快
```

Q4 关断不是"电机立刻停"，而是"12V 停止供能"，续流二极管维持电流直到下次 Q4 导通。

### 15.6 MOSFET 和二极管在 H 桥中的分工

| 器件 | 职责 | 没有它会怎样 |
|------|------|------------|
| MOSFET（Q1-Q4） | 主角：让大电流按指令通断 | STM32 无法直接驱动电机 |
| 肖特基二极管（8个） | 保镖：续流+钳压 | MOSFET 被反向尖峰击穿烧毁 |

**MOSFET 是主角（做功），二极管是保镖（护驾）。**

### 15.7 PWM 调速的本质：控制平均电压

电机速度控制不是"给固定电压然后机械限速"，而是**时而提供12V时而断开，靠占空比控制平均电压**：

```
占空比 75%：
‾‾‾‾‾‾‾‾‾‾‾‾|___
  12V供电      断开

平均电压 = 12V × 75% = 9V → 较快

占空比 25%：
‾‾‾‾|____________
  12V  断开

平均电压 = 12V × 25% = 3V → 较慢
```

电机感受到的不是"时有时无"的抖动，而是这个**平均值**——因为电机线圈是电感，会把断断续续的电压平滑成近似连续的电流。

调速完整链路：

```
改变占空比 → 改变平均电压 → 改变平均电流 → 改变转矩 → 改变转速
```

类比：水龙头不是开和关，而是通过开关频率控制平均水流量。
