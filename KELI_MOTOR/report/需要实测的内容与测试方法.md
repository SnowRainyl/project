# 需要实测的内容与测试方法

本文档用于记录 `main_zh.tex` 中需要实验数据支撑的内容。测试时应保留原始串口日志、逻辑分析仪截图、示波器截图或照片，便于后续填写论文实验章节。

## 一、测试前准备

### 设备

- STM32F407 控制板
- AX309 FPGA 开发板
- JGA25-370 直流减速电机及编码器
- TB6612FNG 电机驱动模块
- INA240A2 电流采样模块
- 电位器、OLED、W25Q64
- 稳压电源
- USB 转串口模块
- 逻辑分析仪或示波器
- 万用表
- 电脑串口工具

### 建议串口记录字段

控制程序最好周期性输出以下数据：

```text
time_ms,setpoint_rpm,measured_rpm,adc_pot,current_ref_mA,current_mA,pwm,integral_speed,integral_current
```

串口输出频率不必达到 1 kHz，建议每 10--20 ms 输出一次，避免大量串口发送影响控制循环。

## 二、必须补测项目

### 1. 电位器零点、死区与积分累积

#### 测试目的

验证以下论述：

- 电位器归零时 ADC 原始值约为 9，而不是严格为 0。
- 不设置死区时，小的目标转速误差会被速度 PID 积分项持续累积。
- 设置 `adc_val < 50` 的死区后，目标转速和积分项不会继续增长。

#### 安全措施

- 首选断开电机驱动输出或强制 PWM 为 0，只观察软件变量。
- 不要让取消死区后的积分测试长时间驱动电机。
- 测试结束后立即恢复死区代码。

#### 测试 A：测量电位器零点

1. 保持当前死区设置不变。
2. 将电位器旋到机械零点。
3. 连续记录 10 s 的 `adc_pot` 原始值。
4. 计算最小值、最大值和平均值。
5. 轻触旋钮但不主动增加转速，再观察 ADC 波动范围。

记录：

| 项目 | 测试结果 |
| --- | --- |
| ADC 最小值 | |
| ADC 最大值 | |
| ADC 平均值 | |
| 是否始终小于 50 | |

通过标准：零点 ADC 存在小偏置，但正常波动始终低于死区阈值 50。

#### 测试 B：验证积分累积

1. 断开电机驱动或强制 PWM 输出为 0。
2. 临时取消 `adc_val < 50` 的死区处理。
3. 将电位器保持在机械零点。
4. 记录 `adc_pot`、`setpoint_rpm`、速度误差和速度积分项。
5. 测试 1--2 s 后停止，避免积分项长时间饱和。
6. 检查积分和是否近似满足

   \[
   S[N]=S[0]+\sum_{k=1}^{N}e[k].
   \]

7. 恢复死区代码并重复测试，确认目标转速被置为 0，积分项不再持续增长。

通过标准：无死区时积分项随时间增长；恢复死区后该增长消失。

### 2. 20、50、100 RPM 稳态误差

#### 测试目的

填写论文“转速控制性能”表格，并验证 0--100 RPM 的闭环调速能力。

#### 测试方法

1. 电机输出轴保持空载，固定电源电压。
2. 分别设置目标转速为 20、50、100 RPM。
3. 每个目标值等待系统进入稳态，建议等待 5 s。
4. 随后连续记录 10 s 的目标转速和实际转速。
5. 对实际转速取平均值，并计算：

   \[
   e_{\mathrm{RPM}}=\overline{\omega}-\omega_{\mathrm{ref}},
   \qquad
   e_{\%}=\frac{|e_{\mathrm{RPM}}|}{\omega_{\mathrm{ref}}}\times100\%.
   \]

记录：

| 给定转速（RPM） | 平均实测转速（RPM） | 误差（RPM） | 绝对误差（%） | 转速波动范围（RPM） |
| ---: | ---: | ---: | ---: | ---: |
| 20 | | | | |
| 50 | | | | |
| 100 | | | | |

通过标准：系统在三个给定点均能稳定运行，无持续振荡；具体误差如实写入论文，不预先虚构合格阈值。

### 3. 转速阶跃响应

#### 测试目的

1. 串口记录 `time_ms`、`setpoint_rpm`、`measured_rpm`、`current_mA` 和 `pwm`。
2. 先保持目标转速为 0，记录约 1 s。
3. 快速将目标值切换到 100 RPM。
4. 持续记录至系统稳定，建议不少于 5 s。
5. 再将目标值从 100 RPM 切回 0，记录减速过程。
6. 使用 Python、Excel 或 MATLAB 绘制目标转速与实际转速随时间变化的曲线。

记录：

| 超调量 | |

建议同时保存启动时的电流和 PWM 曲线，以解释转速响应过程。

### 4. 电流采样零点与运行电流

#### 测试目的

验证 INA240A2 电流采样链路，并复核论文中的“零电流 ADC 约 2200”和“100 RPM 空载电流约 30 mA”。

#### 测试 A：零电流偏置

1. 保持系统上电，但禁止电机驱动。
2. 连续读取 PA1 的 ADC 原始值 10 s。
3. 记录最小值、最大值和平均值。
4. 将平均 ADC 值换算为电压，并作为零点校准值。

#### 测试 B：100 RPM 空载电流

1. 电机输出轴不连接外部负载。
2. 设置目标转速为 100 RPM。
3. 等待系统稳定后记录 10 s 电流数据。
4. 计算平均电流和波动范围。
5. 条件允许时，用万用表串联测量平均电流，和 INA240A2 结果进行对比。

记录：

| 项目 | INA240A2/ADC 结果 | 万用表结果 |
| --- | ---: | ---: |
| 零电流 ADC 平均值 | | 不适用 |
| 零电流输出电压 | | |
| 100 RPM 空载平均电流 | | |
| 100 RPM 电流波动范围 | | |

注意：PWM 电流具有脉动，普通万用表读数与瞬时采样结果可能不同，应比较一段时间内的平均值。

### 5. Flash 参数断电保存

#### 测试目的

验证 PI 参数写入 W25Q64 后，系统断电重启能够自动加载。

#### 测试方法

1. 记录当前 PI 参数。
2. 通过串口将某个参数修改为容易辨认且仍然安全的数值。
3. 执行参数保存命令。
4. 读取一次参数，确认写入成功。
5. 完全断电，等待 5 s 后重新上电。
6. 再次读取参数，检查是否与断电前保存值一致。
7. 将参数恢复为正常控制值并再次保存。

记录：

| 参数 | 修改前 | 保存值 | 重启后读取值 | 是否一致 |
| --- | ---: | ---: | ---: | --- |
| 速度环 Kp | | | | |

| 电流环 Kp | | | | |
| 电流环 Ki | | | | |

通过标准：重新上电后参数与保存值一致，且无有效参数时系统能够使用默认值。

### 6. 串级 PI 参数整定与对比

#### 测试目的

记录速度环和电流环参数的调整过程，为论文第 4.3、4.4 节提供依据。整定时先调电流内环，再调速度外环；每次只修改一个参数。

#### 测试前记录

- 电源电压和负载情况
- 当前固件版本
- 电流零点校准值
- 两个环路的初始参数
- 目标转速或目标电流

#### 测试 A：电流内环

1. 暂时断开速度外环，给电流内环一个较小且安全的固定目标电流。

5. 固定 \(K_p\) 后，从较小值开始增加 \(K_i\)，观察稳定后的电流误差是否减小。
6. 若出现明显超调或持续振荡，降低 \(K_i\)。
7. 恢复速度外环前，确认电流和 PWM 未超过安全范围。

### 9. OLED 与串口显示一致性

1. 在固定转速下同时观察 OLED 和串口输出。
2. 对比目标转速、实际转速、PWM 和电流。
3. 记录是否存在单位、符号、刷新延迟或数值明显不一致。

### 10. 编码器方向和抗干扰

1. 正向运行电机，确认 RPM 符号和方向正确。
2. 停止电机，观察计数是否在无运动时明显跳变。
3. 轻微扰动编码器信号线，观察 TIM3 输入滤波启用后是否仍有大量虚假计数。
4. 不建议直接向引脚注入超出 3.3 V 范围的信号。

该测试主要用于定性确认 `IC1F = IC2F = 0001` 的输入去毛刺功能。若需要严格比较，应使用信号发生器注入可控宽度的 3.3 V 毛刺。

## 四、可选扩展测试

### 11. 带负载测试

在具备安全、可重复的机械负载后，可测试：

- 相同目标转速下空载与带载电流的差异
- 突加负载后的转速跌落和恢复时间
- 电流内环目标值与实际值的跟随情况
- 驱动模块和电机温升

不要用手长期捏住电机轴作为正式负载测试方法。负载应可控，并设置电流、温度和测试时间限制。

### 12. SPI SCK 同步链对照实验

#### 测试目的

比较“规范同步”和“只采样一级”两种实现，观察取消第二级同步后是否出现 SPI 接收错误。该实验用于说明同步链的作用，不用于证明亚稳态一定会在短时间内出现。

#### 对照版本

准备两个 FPGA 工程版本，除 SCK 同步方式外，其余代码保持一致。

版本 A 使用两级同步，并增加一级寄存器保存上一拍，用于边沿检测：

```vhdl
sck_meta <= sck;
sck_sync <= sck_meta;
sck_prev <= sck_sync;
sck_rise <= sck_sync and not sck_prev;
```

版本 B 只进行一级采样，接收逻辑直接使用第一级结果：

```vhdl
sck_sample <= sck;
sck_prev   <= sck_sample;
sck_rise   <= sck_sample and not sck_prev;
```

版本 B 中的 `sck_prev` 只用于保存上一拍，不属于第二级同步器。CS 信号应采用与 SCK 相同的对照方式，避免两版条件不一致。

#### 测试数据

STM32 不运行电机控制，改为循环发送容易识别的固定序列：

```text
0x000, 0x001, 0x555, 0xAAA, 0xFFE, 0xFFF
```

每个数值连续发送固定次数，FPGA 输出对应的 PWM。测试时断开电机驱动，只测量 FPGA 的 SPI 输入和 PWM 输出，避免错误占空比带动电机。

#### 测试方法

1. 先烧录版本 A，SPI2 保持当前 5.25 MHz。
2. 用逻辑分析仪同时采集 `CS_N`、`SCK`、`MOSI` 和 `PWM`。
3. 连续发送测试序列，建议不少于 \(10^6\) 帧。
4. 检查每次发送的数据是否对应正确的 PWM 占空比，记录错误帧数。
5. 烧录版本 B，在接线、测试序列、发送帧数和环境不变的条件下重复测试。
6. 条件允许时，再分别使用 10.5 MHz 和 21 MHz SCK 重复测试，观察系统时钟与 SCK 频率接近后是否更容易出现漏沿或错误接收。
7. 每个频率至少重复测试三次，并保存逻辑分析仪截图和原始记录。

错误率计算为：

\[
\text{错误率}=\frac{\text{错误帧数}}{\text{总发送帧数}}\times100\%.
\]

| FPGA 版本 | SCK 频率 | 总帧数 | 错误帧数 | 错误率 | 现象 |
| --- | ---: | ---: | ---: | ---: | --- |
| A：两级同步 | 5.25 MHz | | | | |
| B：一级采样 | 5.25 MHz | | | | |
| A：两级同步 | 10.5 MHz | | | | |
| B：一级采样 | 10.5 MHz | | | | |
| A：两级同步 | 21 MHz | | | | |
| B：一级采样 | 21 MHz | | | | |

#### 结果解释

- 如果版本 B 出现错误而版本 A 没有，可说明同步链提高了接收可靠性。
- 如果两个版本都没有观察到错误，只能说明本次测试期间未捕获故障，不能证明一级采样不存在亚稳态风险。
- 提高 SCK 后出现错误，既可能与同步级数有关，也可能是 50 MHz 过采样余量不足。特别是 21 MHz 时，一个 SCK 半周期只有约 1.2 个 FPGA 时钟周期，已经不适合用来单独评价亚稳态。
- 亚稳态是概率事件，普通逻辑分析仪通常无法直接观察触发器内部的模拟不稳定过程，只能观察它最终是否造成错误数据、漏沿或重复计数。

### 13. 启动状态机 A/B 对照实验

#### 测试目的

比较“只有死区和普通 PI 控制”和“当前启动状态机”两种实现，确认区分 `STARTING` 和 `RUNNING` 是否能改善低速启动过程。

如果没有该对照数据，报告中不应直接声称状态机已经降低启动超调，只能说明状态机提供了放置启动限流、积分限制和交接处理的清晰结构。

#### 对照版本

版本 A 使用简单启停逻辑：

- 电位器 ADC 小于停止阈值时，电机命令关闭。
- 电位器 ADC 大于启动阈值时，直接进入普通串级 PI 控制。
- 不设置单独的 `STARTING` 状态。
- 不使用启动阶段专用电流上限、启动阶段积分限制和 START-to-RUN 交接削减。
- 保留普通 PI 输出限幅和通用 anti-windup。

版本 B 使用当前状态机实现：

- `IDLE`
- `STARTING`
- `RUNNING`
- `STOPPING`
- 启动电流上限
- 启动阶段速度环积分限制
- 进入 `RUNNING` 前的积分和 duty 交接削减
- target ramp 和 duty slew-rate limit

#### 测试条件

两个版本应保持相同测试条件：

- 相同电机和负载。
- 相同电源电压。
- 相同 PI 参数。
- 相同启停 ADC 阈值。
- 相同目标转速命令。
- 相同 UART 遥测格式。
- 每次测试前电机完全停止。

建议每个目标转速至少重复启动 5 次。

#### 测试点

优先测试低速启动，因为静摩擦影响更明显。

| 测试 | 目标转速 | 目的 |
| --- | ---: | --- |
| 1 | 15 RPM | 接近最小运行命令 |
| 2 | 20 RPM | 低速启动区域 |
| 3 | 30 RPM | 中等启动命令 |

#### 记录数据

每次启动记录以下遥测量：

- state
- target speed
- ramped target speed
- measured RPM
- target current
- measured current
- duty cycle
- potentiometer ADC value

日志应从电机启动前开始记录，并持续到转速稳定。

#### 评价指标

每组测试计算：

- 启动后的峰值 RPM
- 超调百分比
- 从使能到首次转动的时间
- 从使能到达到目标转速的时间
- 稳定时间
- 最大目标电流
- 最大 duty cycle

超调可按下式估算：

\[
\text{超调率}=\frac{\text{峰值 RPM}-\text{最终目标 RPM}}{\text{最终目标 RPM}}\times100\%.
\]

#### 结果解释

- 如果版本 B 的峰值 RPM、超调率、目标电流或 duty 曲线明显更平滑，可在报告中说明状态机和启动处理降低了启动超调。
- 如果差异很小，报告应使用较弱表述：状态机主要改善代码结构，并使启动阶段专用限制更容易实现。
- 如果版本 A 表现更好，应重新调整启动状态机参数，再决定报告中如何表述。
