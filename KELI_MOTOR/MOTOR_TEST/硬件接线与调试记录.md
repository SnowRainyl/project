## 二、FPGA 引脚分配（AX309 J3 扩展口）

> 工具：ISE 14.7（Spartan-6 不支持 Vivado）
> 约束文件：`pin.ucf`

| 信号 | FPGA 引脚 | J3 物理针脚 | 对应 STM32 |
|---|---|---|---|
| clk（50MHz） | P8 | 板载晶振 | — |
| sck | C15 | J3-21 | PB13（SPI2_SCK） |
| cs_n | D16 | J3-23 | PB12（SPI2_CS） |
| mosi | C16 | J3-24 | PB15（SPI2_MOSI） |
| miso | E15 | J3-26 | PB14（SPI2_MISO） |
| pwm_out | F16 | J3-31 | → TB6612 PWMA |

**注意**：J3 是 AX309 板子上方的 40 针排针，背面有引脚名称标注。GND 接任意 GND 针脚与 STM32 共地。

## 三、FPGA VHDL 工程结构

| 文件 | 说明 |
|---|---|
| `spi_slave.vhd` | SPI Slave 接收器，2级同步链消除跨时钟域，接收2字节拼成12bit duty |
| `pwm_gen.vhd` | 12bit 动态PWM发生器，50MHz/4096 ≈ 12.2kHz，duty_valid 锁存 |
| `top.vhd` | 顶层连接：spi_slave → pwm_gen |
| `pin.ucf` | ISE 引脚约束文件 |

**烧录方式**：ISE iMPACT → Boundary Scan → JTAG 直接烧录（断电丢失）。如需上电自动运行需烧录到板载 SPI Flash。

## 五、INA240 电流采样模块分析

### 5.1 模块规格

| 参数 | 值 |
|---|---|
| 芯片 | INA240**A2** |
| 增益 | **50V/V**（A2 版本，注意不是 A1 的 20V/V） |
| 板载采样电阻 | R100 = 0.1Ω（已集成在模块上） |
| VREF1 | 内部已接 GND |
| VREF2 | 内部已接 VCC |
| 零电流输出 | **1.773V**（实测校准值，非理论 1.65V） |

### 5.2 关键结论

- 芯片内部利用 VREF1/VREF2 生成 VCC/2 作为零电流基准，理论值 1.65V。
- **实测零电流时 curr_raw ≈ 2200，对应电压 = 2200/4095×3300 = 1773mV**，故代码校准为 1773mV。
- 增益版本为 **A2（50V/V）**，原先误用 A1 的 20V/V，导致电流读数偏高 2.5 倍，已修正。

代码参数（已校准）：
```c
#define ADC_CURR_INA240_GAIN     50.0f    // INA240A2，增益 50V/V
#define ADC_CURR_SHUNT_MOHM      100.0f   // R100 = 0.1Ω = 100mΩ
#define ADC_CURR_VREF_MV         1773.0f  // 实测零电流校准值
```

### 5.3 电流换算验证

```
curr_raw = 2400 时：
V_out   = 2400/4095 × 3300 = 1934mV
V_shunt = 1934 - 1773 = 161mV
I       = 161mV / (50 × 0.1Ω) = 32mA  ← 与实测吻合
```

空载 100 RPM 时实测约 **30mA**，符合 JGA25-370 空载电流范围（20~150mA）。

### 5.3 接线

| INA240 引脚 | 接到 |
|---|---|
| IN+ | 采样电阻 R100 一端（电机驱动器输出侧） |
| IN- | 采样电阻 R100 另一端（电机侧） |
| OUT | STM32 PA1（ADC1_IN1） |
| VCC | 3.3V |
| GND | 共地（**必须与驱动电路共地**） |

**注意**：模块非隔离采样，驱动电路必须与模块共地。

### 5.4 电流换算公式（代码内）

```
V_shunt = (ADC_raw / 4095.0) × 3300mV - 1650mV
I (mA)  = V_shunt / (增益 × 采样电阻)
        = V_shunt / (20 × 0.1Ω)
        = V_shunt / 2
```

## 十、历史问题记录（已修复）

| 问题 | 现象 | 根本原因 | 修复方法 |
|---|---|---|---|
| OLED 卡死 | 第一屏显示后串口/屏幕均停止刷新 | I2C 每次事务后关闭 PE，AF 标志未清除 | 移除 PE 关闭操作，加超时保护 + 清 AF/BERR/ARLO/OVR 标志 |
| curr 周期性波动 | 电位器归零时 duty/curr 周期性爬升 | adc≈9（非零）→ 速度 PID 积分累积 → 偶发抖转 | adc < 50 设为死区，setpoint_rpm = 0 |
| 电流读数偏高 2.5 倍 | 100 RPM 时显示 ~150mA，实际 ~30mA | 增益参数误用 A1（20V/V），实际模块为 A2（50V/V） | ADC_CURR_INA240_GAIN 改为 50.0f |
| duty 振荡 0~100% | 电流一直负偏差，内环极限环振荡 | MOTOR_MAX_CURRENT_MA=150mA 低于电机实际电流 200~300mA | 改为 400mA，同步更新 speed_pid integral_max=4000 |
| 零电流偏差 | 静止时 curr ≈ 60mA | ADC_CURR_VREF_MV=1650 与实测 1773mV 不符 | 校准为 1773mV（raw≈2200 @ 零电流 → 2200/4095×3300） |
