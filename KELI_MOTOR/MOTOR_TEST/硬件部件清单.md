# 硬件部件清单

> 项目：KELI_MOTOR 直流电机串级闭环控制系统
> 整理日期：2026-04-18

---

## 1. STM32F407G-DISC1 主控板

- **一句话描述**：意法半导体 STM32F407 系列 Cortex-M4 开发板，板载 ST-Link/V2-A 调试器，主频 168MHz。
- **相关资料**：
  - RM0090 — STM32F405/407/415/417 Reference Manual（全部外设寄存器，ST 官网搜 RM0090）← **用到：项目所有寄存器级驱动（ADC/SPI/I2C/TIM/USART）的配置依据，是最核心的参考手册**
  - PM0214 — Cortex-M4 Programming Manual（NVIC/SysTick/指令集）← **本项目用不到**（只有写汇编或自己实现 RTOS 才需要）
  - UM1472 — STM32F4DISCOVERY User Manual（板子引脚/电路图）← **本项目用不到**（排查 ST-Link VCP 失效时查过一次，结论是换 CH340，之后不再需要）
  - DS8626 — STM32F407VG Datasheet（引脚复用表 Table 9，AF 功能选择必查）← **用到：配置 SPI/I2C/TIM 引脚时需查 AF 编号**（例如 PA5 = SPI1_SCK 对应 AF5）
- **项目用处**：系统主控 MCU。负责 ADC 采样（电位器+电流）、TIM6 1kHz 定时中断驱动串级 PID、SPI2 与 FPGA 通信发 PWM 占空比、SPI1 与 W25Q64 Flash 通信、I2C1 驱动 OLED、USART2 串口调试。

---

## 2. ALINX AX309 FPGA 开发板

- **一句话描述**：Xilinx Spartan-6 XC6SLX9-2FTG256 FPGA 开发板，板载 50MHz 晶振、4 位数码管、按键、JTAG 接口。
- **相关资料**：
  - AX309 用户手册（ALINX 官网或资料包，含原理图和 J3 引脚定义）← **用到：确定 J3 扩展口各针脚对应的 FPGA 引脚编号（sck/cs_n/mosi/pwm_out 的接线位置）**
  - DS160 — Spartan-6 FPGA Data Sheet（芯片电气特性）← **本项目用不到**（IO 电气参数在本项目不是瓶颈）
  - UG381 — Spartan-6 FPGA SelectIO Resources（IO 电平标准）← **本项目用不到**（本项目 IO 全用默认 LVCMOS33，不需要特殊配置）
  - Spartan-6 Libraries Guide for HDL Designs（ISE 综合原语，ISE 安装目录自带）← **本项目用不到**（VHDL 只用了基本语法，没有调用任何 ISE 原语）
- **项目用处**：负责生成 12-bit 高频 PWM（50MHz/4096 ≈ 12.2kHz）驱动电机驱动器。通过 SPI Slave 接收 STM32 发来的占空比，PWM 输出至 TB6612 PWMA 引脚。VHDL 工程：`spi_slave.vhd` + `pwm_gen.vhd` + `top.vhd`。

---

## 3. JGA25-370 直流减速电机（带编码器）

- **一句话描述**：12V 额定电压、约 280RPM 额定空载转速的直流有刷减速电机，带霍尔编码器输出转速反馈。
- **相关资料**：
  - JGA25-370 规格书（购买页面或淘宝商家资料，含编码器线序）← **用到：确认编码器 A/B 相线序和供电电压（接错会导致 RPM=0）**
  - STM32 TIM3 编码器模式：RM0090 第 18 章（General-purpose timers），SMS=011（Encoder mode 3）← **用到：TIM3 正交解码配置，encoder_reg.c 的实现依据**
- **项目用处**：被控对象。编码器接 STM32 TIM3（PC6/PC7）做正交解码，速度环目标值 0~100 RPM 平滑可控，稳态误差 < 1%。

---

## 4. TB6612FNG 电机驱动模块

- **一句话描述**：东芝双路 H 桥直流电机驱动芯片模块，单路最大持续电流 1.2A，支持 PWM 调速和方向控制。
- **相关资料**：
  - TB6612FNG Datasheet（Toshiba，搜 "TB6612FNG datasheet"）← **用到：查真值表确认 AIN1/AIN2/STBY 引脚的控制逻辑，以及 STBY 必须拉高才能工作**
- **项目用处**：把 FPGA 输出的 3.3V PWM 信号放大到电机驱动电流。本项目固定 AIN1=高/AIN2=低（单方向），PWMA 接收 FPGA PWM，AO1/AO2 接电机两端。STBY 必须拉高否则待机不工作。

---

## 5. INA240A2 电流采样放大器模块

- **一句话描述**：TI 高共模电压双向电流分流监视器，A2 版本增益 50V/V，模块板载 R100 = 0.1Ω 采样电阻。
- **相关资料**：
  - INA240 Datasheet（TI 官网，搜 "INA240"）← **用到：确认 A2 版本增益为 50V/V，推导电流换算公式，以及 REF 引脚接法（决定零电流时输出电压）**
- **项目用处**：测量电机绕组电流作为电流内环反馈。OUT 接 STM32 PA1（ADC1_IN1）。零电流输出实测约 1.773V，100RPM 空载电流 ~30mA，与铭牌一致。

---

## 6. 电位器（旋钮式）+ RC 低通滤波器

- **一句话描述**：碳膜旋钮电位器（10kΩ 量级），输出端经 RC 滤波后接 STM32 PA0（ADC1_IN0）。
- **相关资料**：
  - RM0090 第 11 章 — ADC（STM32 ADC 寄存器配置）← **用到：adc_reg.c 中 ADC1 双通道采样的配置依据**
  - RC 滤波截止频率 f = 1/(2πRC)← **本项目用不到计算**（滤波电容/电阻已经选好焊好，不需要重新算）
- **项目用处**：用户输入设备，旋转旋钮设定速度环目标转速（0~100 RPM 映射）。RC 滤波消除电源噪声，软件再加 16 点均值滤波 + adc<50 死区抑制零点漂移。

---

## 7. 0.96" OLED 显示屏（SSD1306 I2C）

- **一句话描述**：128×64 像素单色 OLED 屏，驱动芯片 SSD1306，I2C 接口，4 针（GND/VCC/SCL/SDA）。
- **相关资料**：
  - SSD1306 Datasheet（Solomon Systech，搜 "SSD1306 datasheet PDF"）← **用到：初始化命令序列（OLED_SSD1306.c 的开屏指令来源）、I2C 地址 0x3C**
  - RM0090 第 27 章 — I2C（STM32 I2C 寄存器，START/ADDR/STOP 时序）← **用到：custom_i2c.c 中 I2C1 寄存器配置和超时保护的实现依据**
- **项目用处**：实时显示项目名、当前转速 RPM、PWM 占空比 %、电机电流 mA。SCL 接 PB6，SDA 接 PB7，I2C1 硬件外设驱动，5Hz 刷新与串口同步。

---

## 8. W25Q64FV SPI Flash

- **一句话描述**：Winbond 8MB（64Mbit）NOR SPI Flash 存储芯片，最高 SPI 时钟 104MHz，4KB 扇区可擦写。
- **相关资料**：
  - W25Q64FV Datasheet（Winbond 官网，搜 "W25Q64FV datasheet"）← **用到：w25q64.c 中所有指令字节（Read ID / Page Program / Sector Erase）均来自此手册的指令集表**
  - RM0090 第 28 章 — SPI（STM32 SPI 寄存器配置）← **用到：SPI1 寄存器配置依据（与 SPI2 共用同一章）**
- **项目用处**：预留用于持久化 PID 参数、运行日志等数据。**芯片目前未接线**，接线后需重新验证读写。

---

## 9. CH340G USB-TTL 串口模块

- **一句话描述**：南京沁恒 CH340G USB 转串口芯片模块，自带 12MHz 晶振，USB-A 公头直插电脑。
- **相关资料**：
  - CH340 Datasheet（沁恒官网 wch.cn，搜 "CH340DS1"）← **本项目用不到**（CH340 模块直接插电脑用，不需要了解芯片内部）
  - Windows 驱动：CH341SER.EXE（沁恒官网下载）← **用到：电脑上必须装这个驱动才能识别 COM12 端口**
  - RM0090 第 30 章 — USART（STM32 波特率 BRR 计算）← **用到：uart.c 中 USART2 波特率寄存器 BRR 的计算依据（115200bps@84MHz）**
- **项目用处**：替代失效的 ST-Link VCP 用作串口调试通道。TXD→PA3、RXD→PA2、GND→共地，电脑端 PuTTY/串口助手 115200 8N1 接收实时调试数据。

## 10. UNI-T UTP1306S 直流稳压电源

- **一句话描述**：优利德 32V/6A 单路可调线性直流电源，电压电流双显示，支持 OVP/OCP 保护。
- **相关资料**：
  - UTP1306S 用户手册（UNI-T 官网 uni-trend.com.cn）← **本项目用不到**（电源只需会调电压/电流旋钮，不需要查手册）
- **项目用处**：为电机驱动器 VM 引脚提供 12V 主电源（非 STM32/FPGA 逻辑电源）。设置限流 1A 防止短路或堵转烧驱动器。

- **相关资料**：
